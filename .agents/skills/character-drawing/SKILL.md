# Character Drawing Skill

## Purpose

This skill constructs characters progressively using traditional figure-drawing methodology.

The goal is NOT to independently generate multiple illustrations representing different stages.

The goal is to progressively build ONE drawing.

The drawing evolves through:

Gesture
→ Skeleton
→ Mannequin
→ Construction
→ Anatomy
→ Clean Line
→ Rendering

Every stage inherits the structure established by previous stages.

---

# Fundamental rule

NEVER redraw the character independently between passes.

Each drawing pass MUST preserve:

- canvas
- camera
- framing
- pose
- proportions
- line of action
- joint positions
- limb directions
- body orientation
- perspective

Later passes ADD information to the existing construction.

They must not reinterpret the character.

---

# Sources of truth

Three representations are used.

## CharacterSpec

Describes artistic intent.

Example:

- adult
- athletic
- 7.5 heads tall
- standing
- weight on right leg
- left arm raised
- three-quarter camera

The CharacterSpec MUST NOT contain arbitrary generated joint coordinates.

Geometry must be resolved deterministically whenever possible.

## Resolved geometry

Generated by the geometry scripts.

Contains:

- landmarks
- joints
- bones
- proportions
- primitive body volumes

This geometry becomes LOCKED once drawing begins.

## DrawingState

Tracks the actual drawing process.

It records:

- current pass
- completed passes
- geometry
- construction strokes
- reference image
- locked properties

# Drawing pipeline

Always use the following order.

## PASS 1 — Gesture

Purpose:

Capture movement, rhythm and balance.

Draw ONLY:

- line of action
- head direction
- shoulder axis
- hip axis
- major limb direction
- ground/contact indication

Do NOT draw:

- anatomy
- clothing
- facial features
- fingers
- muscles
- detailed contours

Read:

`references/gesture.md`

---

## PASS 2 — Skeleton

Purpose:

Establish proportions and articulation.

Preserve all gesture decisions.

Add:

- head
- neck
- spine
- shoulders
- pelvis
- upper arms
- forearms
- thighs
- lower legs
- hands
- feet
- joints

Read:

`references/proportions.md`

`references/skeleton.md`

Use geometry scripts when available.

---

## PASS 3 — Mannequin

Purpose:

Convert the skeleton into simple 3D masses.

DO NOT remove or reposition the skeleton.

Add:

- head volume
- rib cage
- pelvis
- shoulder volumes
- upper arm cylinders
- forearm cylinders
- thigh volumes
- calf volumes
- hand wedges
- foot wedges

Use cross-contours to communicate orientation.

Read:

`references/mannequin.md`

---

## PASS 4 — Construction

Purpose:

Connect primitive volumes into a coherent human form.

Preserve underlying mannequin.

Add:

- body flow
- connections between masses
- simplified silhouette
- major overlaps
- torso transitions
- limb transitions

Construction lines should remain visible.

Read:

`references/construction.md`

---

## PASS 5 — Anatomy

Purpose:

Refine the construction using major anatomical masses.

Add only major forms.

Prioritize:

- neck
- shoulders
- chest
- abdomen
- back
- upper arms
- forearms
- thighs
- calves

Do not over-detail muscles.

Read:

`references/anatomy.md`

---

## PASS 6 — Clean Line

Purpose:

Extract the final readable drawing.

Use the construction as the source.

Do NOT reinterpret anatomy or pose.

Gradually reduce construction lines.

Add:

- final contour
- overlaps
- face
- hair
- hands
- clothing
- accessories

Read:

`references/line-work.md`

---

## PASS 7 — Rendering

Purpose:

Add light, material and final details.

The silhouette and geometry are now LOCKED.

Add:

- primary light
- form shadows
- cast shadows
- material separation
- texture
- final details

Do not modify anatomy during rendering.

---

# Image generation protocol

When an image-generation model is available, NEVER ask it to create all drawing stages independently.

Generate one pass at a time.

The output image of pass N becomes the visual input of pass N+1.

Pipeline:

```text
CharacterSpec
     ↓
Geometry
     ↓
Gesture image
     ↓
Skeleton image
     ↓
Mannequin image
     ↓
Construction image
     ↓
Anatomy image
     ↓
Clean line
     ↓
Final render
```

---

# Pass transition rules

For every image transformation:

PRESERVE EXACTLY:

- pose
- framing
- canvas dimensions
- head position
- shoulder position
- pelvis position
- elbow position
- wrist position
- knee position
- ankle position
- perspective

The next pass may:

ADD strokes.

REFINE strokes.

LIGHTEN previous construction strokes.

It must NOT:

move joints,
change pose,
change camera,
change body proportions,
change character orientation,
redesign previous geometry.

---

# Image-model instruction

Use this base instruction for progressive drawing:

> Continue the supplied drawing rather than redrawing the character.
>
> Treat every existing construction mark as structural information.
>
> Preserve exactly the pose, proportions, camera, framing, joint positions,
> body orientation and perspective.
>
> Add only the information required by the requested drawing pass.
>
> Do not silently correct or reinterpret the pose.
>
> This image is one frame in a progressive drawing process.

Then append the instructions for the current pass.

# Progressive visibility

Construction should visually evolve.

Recommended opacity hierarchy:

Gesture:
100%

Skeleton pass:
gesture 35%
skeleton 100%

Mannequin:
gesture 15%
skeleton 35%
volumes 100%

Construction:
skeleton 15%
volumes 35%
construction 100%

Anatomy:
volumes 20%
construction 40%
anatomy 100%

Clean line:
construction 10–20%
clean line 100%

Final:
clean line + rendering

---

# Validation

Before moving to the next pass check:

1. Are proportions consistent?
2. Did any joint move?
3. Did camera/framing change?
4. Did the silhouette accidentally change the pose?
5. Does the center of gravity remain plausible?
6. Do volumes follow the skeleton?
7. Does perspective remain coherent?

If structural errors exist, fix the CURRENT pass.

Do not compensate for structural errors in later passes.
