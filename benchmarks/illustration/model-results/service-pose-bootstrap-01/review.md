# Production service pose bootstrap

The rebuilt service benchmark completed five real passes, publishing at 8.8,
15.8, 22.8, 30.1 and 37.1 seconds. Source guide was imported into isolated
Akasha storage; the service archived an exact byte-for-byte copy under its run
ID. `publication-5.json` persists seed 42 and that archived guide path. PNG
export succeeded; review still reports accepted=false / needs_review.

The final was inspected: two arms, identifiable elderly figure, pipe, chair and
garden. No convincing smoke is visible, footwear retains toe-like shapes, and
chair perspective guides survive. Not accepted as finished professional artwork.
The source guide and construction are preselected fixtures, not automatically
authored for arbitrary requests. The service appends the saved style to the brief,
so this is not a pixel-identical replay of the lightweight runner.

Validation: all-target checks pass for platform, agent and UI. Four filtered
platform tests pass (including path/PNG rejection and retained guide metadata on
retouch); 25 aos-sd library tests passed for the underlying pass implementation.
This test exercises the production service and storage, not desktop rendering,
IPC transport, a running daemon restart, or autonomous agent guide selection.
