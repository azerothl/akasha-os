# Skeleton Construction

The drawing skeleton is an artistic structural model.

It is not a medically complete skeleton.

## Main hierarchy

root
→ pelvis
→ spine
→ chest
→ neck
→ head

Chest branches into:

shoulder
→ upper arm
→ elbow
→ forearm
→ wrist
→ hand

Pelvis branches into:

hip
→ thigh
→ knee
→ lower leg
→ ankle
→ foot

## Joints

Clearly establish:

- shoulders
- elbows
- wrists
- hips
- knees
- ankles

## Spine

Never treat the torso as one rigid straight line.

The spine communicates:

- torso bend
- rotation
- compression
- extension

## Rule

Bones establish LENGTH and DIRECTION.

Volumes establish MASS.
