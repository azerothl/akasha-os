# Gesture Drawing

Gesture establishes movement before anatomy.

The purpose is not to describe the body surface.

It describes:

- movement
- balance
- rhythm
- direction
- weight

## Line of action

Find the dominant directional curve running through the figure.

Prefer one clear curve over many small curves.

Common shapes:

C curve

S curve

straight directional thrust

## Head

Represent the head using a simple oval.

Add:

- vertical center line
- horizontal eye axis

These lines communicate orientation.

## Shoulder axis

Draw a line connecting the shoulders.

The line should reflect torso orientation.

## Hip axis

Draw a line connecting the hips.

Shoulder and hip axes are rarely perfectly parallel in natural poses.

## Limbs

Represent limbs using directional strokes.

Do not draw contours yet.

## Balance

Determine the weight-bearing leg.

Estimate the center of gravity.

For a stable standing pose, the body's center of mass should project reasonably near the support area.

## Rule

Gesture describes ENERGY.

Skeleton describes STRUCTURE.

Do not confuse them.
