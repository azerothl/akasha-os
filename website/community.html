Cohort gate

Gate cohorte

Success is 3 Windows + 1 Linux + 1 macOS Apple Silicon testers completing the short path below, each with a usable var/feedback/ report. Preview is a host app, not a bootable OS. Intel Mac is out. NVIDIA is recommended on Windows and Linux; CPU-only is slower but counts. macOS builds are unsigned — expect Gatekeeper after install.sh.

Le succès, c’est 3 Windows + 1 Linux + 1 macOS Apple Silicon qui finissent le chemin court ci-dessous, chacun avec un rapport var/feedback/ exploitable. La Preview est une appli hôte, pas un OS bootable. Pas d’Intel Mac. NVIDIA est recommandé sous Windows et Linux ; le CPU-only est plus lent mais compte. Les builds macOS ne sont pas signés — Gatekeeper avertira après install.sh.

Short path (15 minutes)

Chemin court (15 minutes)

This is enough to count toward the gate. Skip what your hardware cannot do, and say so in the report. The long protocol in feedback is a team checklist, not a drill for every tester.

Cela suffit pour compter dans la gate. Sautez ce que votre matériel ne permet pas, et dites-le dans le rapport. Le protocole long dans feedback est une checklist équipe, pas un drill pour chaque testeur.

  1. Install from GitHub Releases — install.ps1 (Windows) or ./install.sh (Linux / macOS Apple Silicon).
  2. Installer depuis les GitHub Releases — install.ps1 (Windows) ou ./install.sh (Linux / macOS Apple Silicon).
  3. Launch Akasha OS Preview. Finish model setup and the four-step tutorial.
  4. Lancer Akasha OS Preview. Terminer le choix des modèles et le tutoriel en quatre étapes.
  5. Chat tab, network still off: ask “What is Akasha OS?” and wait for a streamed reply.
  6. Onglet Chat, réseau encore off : demander « Qu’est-ce qu’Akasha OS ? » et attendre une réponse streamée.
  7. Notes tab: title + body → Create, then List.
  8. Onglet Notes : titre + corps → Create, puis List.
  9. Feedback tab: Send feedback. Keep Create a GitHub issue checked (except security). Confirm Submit on GitHub if you have an account.
  10. Onglet Feedback : Send feedback. Laisser Create a GitHub issue coché (sauf security). Confirmer Submit sur GitHub si vous avez un compte.

Where to talk

Où parler

Open a check-in on GitHub Discussions with your OS, GPU or CPU, and whether chat and notes worked. Ask questions there. Share a skill or a module as Show and tell — that is not a pull request and does not grant the commercial license. Bugs still go through the Feedback tab so var/feedback/ is attached.

Ouvrez un check-in sur GitHub Discussions avec votre OS, GPU ou CPU, et si chat et notes ont marché. Posez les questions là. Partagez un skill ou un module en Show and tell — ce n’est pas une pull request et cela n’accorde pas la licence commerciale. Les bugs passent encore par l’onglet Feedback pour attacher var/feedback/.

There is no Discord. Messaging channels are out of the OS core; this page is for humans. Code of conduct and security policy live in the repository with how to contribute.

Pas de Discord. Les canaux de messagerie sont hors du noyau OS ; cette page est pour les humains. Le code de conduite et la politique de sécurité vivent dans le dépôt avec comment contribuer.
