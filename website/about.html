Ākāśa, the medium. Ākāśa, le milieu.

Akasha OS is not an agent runtime bolted onto a general-purpose OS. The name is the thesis: a system meant as the space agents occupy, not a guest on someone else’s kernel. The references below are inspirations, not affiliations.

Akasha OS n’est pas un runtime d’agents posé sur un OS généraliste. Le nom est la thèse : un système pensé comme l’espace qu’occupent les agents, pas comme un invité sur le noyau d’un autre. Les références ci-dessous sont des inspirations, pas des affiliations.

Ether

Éther

In Sanskrit, ākāśa names the sky, space, the fifth element: the medium in which the other elements exist. Later esoteric traditions speak of akashic records — a reservoir of what has been thought and done. For this OS that is not omniscience. It is memory, knowledge, and agents as first-class services; typed intents on a bus; a substrate, not a séance.

En sanskrit, ākāśa désigne le ciel, l’espace, le cinquième élément : le milieu dans lequel les autres existent. Des traditions ésotériques parlent ensuite d’archives akashiques — un réservoir de ce qui a été pensé et fait. Pour cet OS, ce n’est pas l’omniscience. C’est la mémoire, la connaissance et les agents comme services de premier plan ; des intents typés sur un bus ; un substrat, pas une séance.

Origin

Origine

In Anne Rice’s The Queen of the Damned, Akasha is the first vampire, source of the others. For an OS, that image is a foundational system: first of its line, the base on which the rest is built. Today that base is still a host Preview 0.10.0, with a separate seL4 track in the repository exploring what comes after.

Dans La Reine des damnés d’Anne Rice, Akasha est la première vampire, source des autres. Pour un OS, cette image est celle d’un système fondateur : premier de sa lignée, base sur laquelle le reste se construit. Aujourd’hui cette base reste une Preview hôte 0.10.0, avec une piste seL4 séparée dans le dépôt qui explore la suite.

Sound

Son

Short, fluid, uncommon. Easy to remember; elegant and forceful at once. A mark rather than a generic tech acronym — something you can say aloud without explaining five letters.

Court, fluide, peu commun. Facile à retenir ; élégant et puissant à la fois. Une marque plutôt qu’un acronyme tech générique — quelque chose que l’on peut dire à voix haute sans épeler cinq lettres.

Frame

Cadre

The name signals a break with POSIX as the agent’s native tongue. Akasha OS aims to be agent-native: capabilities, audit, and policy at the core — more than a chat wrapper sitting on Windows or Linux. Preview is the scaffold you can install today; the name points at the system we are building toward.

Le nom signale une rupture avec POSIX comme langue native de l’agent. Akasha OS se veut agent-natif : capacités, audit et politiques au cœur — plus qu’un wrapper de chat posé sur Windows ou Linux. La Preview est l’échafaudage que vous pouvez installer aujourd’hui ; le nom pointe vers le système vers lequel nous construisons.
