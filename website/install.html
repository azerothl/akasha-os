Platform notes

Notes de plateforme

Windows 10/11 x64, Linux x64, and macOS on Apple Silicon are supported. Intel Mac is not. On Windows and Linux, NVIDIA with a recent driver is recommended (nvidia-smi -L); the CUDA runtime ships in the package, so the driver is enough. A CPU path is available in Preview 0.13.0 via Settings → Inference — no second zip required. The macOS build is unsigned — Gatekeeper will warn after download.

Windows 10/11 x64, Linux x64 et macOS sur Apple Silicon sont pris en charge. Mac Intel n’est pas pris en charge. Sous Windows et Linux, NVIDIA avec un pilote récent est recommandé (nvidia-smi -L) ; le runtime CUDA est fourni dans le paquet, le pilote suffit. Un chemin CPU est disponible en Preview 0.13.0 via Réglages → Inférence — pas de second zip. Le build macOS est non signé — Gatekeeper avertira après le téléchargement.

Windows step by step

Windows pas à pas

  1. Download the unified zip AgentOS-Preview-<ver>-windows-x64.zip (CUDA and CPU backends inside) from GitHub Releases.
  2. Télécharger le zip unifié AgentOS-Preview-<ver>-windows-x64.zip (backends CUDA et CPU inclus) depuis GitHub Releases.

.\install.cmd

Prefer install.cmd — it bypasses a Restricted PowerShell policy. The equivalent is powershell -ExecutionPolicy Bypass -File .\install.ps1. Files land under %LOCALAPPDATA%\AgentOS-Preview; updates keep var/ and etc/. Launch Akasha OS Preview from the Start menu or shortcut.

Les fichiers vont sous %LOCALAPPDATA%\AgentOS-Preview ; les mises à jour conservent var/ et etc/. Lancez Akasha OS Preview depuis le menu Démarrer ou le raccourci.

If something goes wrong

Si quelque chose ne va pas

  • No NVIDIA (Win/Linux) → use Settings → Inference → CPU (slow is OK), or a CPU-oriented archive if you downloaded one separately
  • Pas de NVIDIA (Win/Linux) → Réglages → Inférence → CPU (lent OK), ou une archive orientée CPU si vous en avez téléchargé une à part
  • Gatekeeper blocked macOS launch → run ./install.sh again or right-click Open on bin/aos-session
  • Gatekeeper bloque le lancement macOS → relancer ./install.sh ou clic droit Ouvrir sur bin/aos-session
  • Model download failed → need network to Hugging Face, or copy GGUFs into share/models/
  • Échec téléchargement modèle → réseau vers Hugging Face, ou copier les GGUF dans share/models/
  • Healthcheck failed → check var/run/*.stderr.log (Troubleshooting button)
  • Healthcheck failed → voir var/run/*.stderr.log (bouton Troubleshooting)
  • Bus unreachable → always launch via aos-session
  • Bus unreachable → toujours lancer via aos-session

Build from source

Compiler depuis les sources

Releases are enough to run Preview. Build from source for a local package, patches, or development. Full write-up: docs/build and INSTALL.md.

Les Releases suffisent pour lancer la Preview. Compilez depuis les sources pour un paquet local, des patches ou du développement. Détail : docs/build et INSTALL.md.

  • Stable Rust plus the wasm32-unknown-unknown target
  • Rust stable plus la cible wasm32-unknown-unknown
  • CUDA Toolkit (nvcc) with a working nvidia-smi
  • CUDA Toolkit (nvcc) avec un nvidia-smi qui répond
  • cmake · ninja · clang/libclang (Linux)(Linux) 
# Windows
.\packaging\build-preview.ps1 -SkipModels -RequireCuda

# Linux
SKIP_MODELS=1 REQUIRE_CUDA=1 ./packaging/build-preview.sh

# Dev run (repo root)
$env:AOS_HOME = (Resolve-Path .)   # Windows
export AOS_HOME="$(pwd)"           # Linux
cargo run -p aos-session --release
