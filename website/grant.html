Sessions

Sessions

Chat keeps several conversations side by side. Each session stores its own history and can pick its own model from the offerings listed under Models. After you close Preview and open it again, those histories are expected to return. Stop cancels an in-flight generation; Copy puts a message on the clipboard. Slash commands such as /agent, /image, and /speak attach media or background agents to the thread.

Le Chat garde plusieurs conversations côte à côte. Chaque session conserve son historique et peut choisir son propre modèle parmi les offres listées sous Models. Après fermeture et réouverture de la Preview, ces historiques sont censés revenir. Stop annule une génération en cours ; Copier met un message dans le presse-papiers. Des commandes slash comme /agent, /image et /speak rattachent média ou agents de fond au fil.

Local models and GPU placement

Modèles locaux et placement GPU

On first launch, Preview probes VRAM, RAM, and disk, then offers a GGUF pack suited to your tier — including a CPU pack when NVIDIA is absent. Models lists installed entries, downloads alternatives, and shows live metrics. Settings Inference auto / GPU / CPU can migrate a live completion mid-token on NVIDIA hosts. Optional image and TTS packs are not in the zip; downloading them also fetches the sd.cpp or Piper engine when needed.

Au premier lancement, la Preview sonde VRAM, RAM et disque, puis propose un pack GGUF adapté à votre palier — y compris un pack CPU sans NVIDIA. Models liste les entrées installées, télécharge des alternatives et affiche des métriques en direct. Settings Inférence auto / GPU / CPU peut migrer une complétion en cours au milieu d’un token sur hôtes NVIDIA. Les packs image et TTS optionnels ne sont pas dans le zip ; les télécharger tire aussi le moteur sd.cpp ou Piper si besoin.

Network stays opt-in

Le réseau reste en opt-in

Search, browse, and fetch are disabled until you enable Allow network. With the default offline mode, web search is expected to fail closed. When you do enable it, the engine preference auto tries Brave, then DuckDuckGo, then Bing. An optional Brave key lives under Settings → Secrets. Chat with local models does not require the network once weights are on disk.

Recherche, browse et fetch restent désactivés tant que vous n’activez pas Allow network. En mode hors ligne par défaut, la recherche web est censée échouer de façon fermée. Quand vous l’activez, la préférence auto essaie Brave, puis DuckDuckGo, puis Bing. Une clé Brave optionnelle vit sous Settings → Secrets. Le chat avec des modèles locaux n’a pas besoin du réseau une fois les poids sur disque.

Audit and confirmation

Audit et confirmation

The Audit tab shows signed events. Sensitive agent actions raise a confirmation banner: you can deny once and accept another time; timeout refuses the action. Feedback writes a local report under var/feedback/ and can open a GitHub issue when you choose. Security-sensitive reports are kept local rather than published automatically.

L’onglet Audit montre des événements signés. Les actions sensibles d’agent affichent une bannière : vous pouvez refuser une fois et accepter une autre ; le timeout refuse l’action. Le feedback écrit un rapport local sous var/feedback/ et peut ouvrir une issue GitHub si vous le choisissez. Les rapports liés à la sécurité restent locaux plutôt que publiés automatiquement.

Long-term memory

Mémoire long terme

The Memory tab stores durable user facts — for example that you prefer French — and lets you recall, edit, or supersede them. Before inference, Chat can inject matching context. Auto-remember from chat is on by default: after a turn, Preview may propose facts with a [chat] badge while filtering secrets so keys and tokens are not stored by accident.

L’onglet Memory stocke des faits utilisateur durables — par exemple que vous préférez le français — et permet de les rappeler, éditer ou remplacer. Avant l’inférence, le Chat peut injecter le contexte correspondant. La mémorisation auto depuis le chat est activée par défaut : après un tour, la Preview peut proposer des faits avec un badge [chat] tout en filtrant les secrets pour ne pas stocker clés et jetons par accident.

Notes and tasks

Notes et tâches

Notes and Tasks ship as WASM modules with a dual surface: the human tabs and the agent tools share the same store. You create and list notes or tasks in the UI; an agent can call the matching tools with the same data. Packaged modules resync on boot after a Preview update so a newer package is not left behind a stale copy.

Notes et Tasks sont livrés en modules WASM à double surface : les onglets humains et les outils agent partagent le même store. Vous créez et listez notes ou tâches dans l’UI ; un agent peut appeler les outils correspondants sur les mêmes données. Les modules empaquetés se resynchronisent au boot après une mise à jour Preview pour qu’un paquet plus récent ne laisse pas une copie périmée.

Agents, skills, and tools

Agents, skills et outils

The Agents tab starts a goal loop with a task and a model. Preview ships skills such as notes-writer, research, file-author, planner, and tasks under share/skills/. Tools may be native, module-backed, MCP stdio servers, or runtime helpers for plan and spawn. Detail shows the step timeline; you can pause, resume, steer, or kill. Optional MCP servers are configured from share/mcp/servers.yaml.example.

L’onglet Agents démarre une boucle de goal avec une tâche et un modèle. La Preview livre des skills comme notes-writer, research, file-author, planner et tasks sous share/skills/. Les outils peuvent être natifs, portés par un module, des serveurs MCP stdio, ou des aides runtime pour plan et spawn. Détail montre la timeline des étapes ; vous pouvez pauser, reprendre, steerer ou tuer. Les serveurs MCP optionnels se configurent depuis share/mcp/servers.yaml.example.

Image Studio and speech

Image Studio et parole

After you download an image pack from Models, the Image tab becomes a studio: prompt, size, steps, CFG, seed, sampler, styles, LoRAs, optional upscale, and a composition canvas that turns placement blocks into structured layout for the prompt. Chat /image and /speak write PNG or WAV under downloads once the matching pack (and engine) is present. A TTS card can open from /speak so you set voice knobs before generating.

Après téléchargement d’un pack image depuis Models, l’onglet Image devient un studio : prompt, taille, steps, CFG, seed, sampler, styles, LoRA, upscale optionnel, et un canvas de composition qui transforme des blocs de placement en layout structuré pour le prompt. Le chat /image et /speak écrivent PNG ou WAV sous downloads une fois le pack (et le moteur) présents. Une carte TTS peut s’ouvrir depuis /speak pour régler la voix avant de générer.

Non-destructive updates

Mises à jour non destructives

When a newer GitHub Release exists, a banner can appear. Download stores the archive under var/updates/; the next launch overlays bin/ and share/ without wiping var/ or blindly overwriting your etc/*.yaml (conflicting files get a .new sibling). Apply is intentional across launches, not a silent in-place rewrite of your whole home.

Quand une Release GitHub plus récente existe, une bannière peut apparaître. Le téléchargement stocke l’archive sous var/updates/ ; le lancement suivant superpose bin/ et share/ sans effacer var/ ni écraser aveuglément vos etc/*.yaml (les conflits reçoivent un frère .new). L’application est volontaire d’un lancement à l’autre, pas une réécriture silencieuse de tout le home.
