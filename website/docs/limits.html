Preview 0.14.0 is a host app on Windows or Linux. It is not the long-term seL4 system. The boundaries below are deliberate choices for this Preview, stated in the same register as the thesis. La Preview 0.14.0 est une appli hôte sur Windows ou Linux. Ce n’est pas le système seL4 à long terme. Les frontières ci-dessous sont des choix délibérés pour cette Preview, dits dans le même registre que la thèse.

Honesty first

Honnêteté d’abord

Nothing here is a promise that the feature arrives next week. Each item explains why Preview stops where it does, so you can decide whether the host is enough for your test.

Rien ici n’est une promesse que la fonctionnalité arrive la semaine prochaine. Chaque point explique pourquoi la Preview s’arrête là, pour que vous puissiez juger si l’hôte suffit à votre test.

Host, not bare metal

Hôte, pas bare metal

Preview installs and runs on top of Windows or Linux. A bootable / bare-metal image is a separate seL4 track in the repository. Keeping that boundary clear avoids confusing an installable tester build with the long-term OS goal.

La Preview s’installe et tourne au-dessus de Windows ou Linux. Une image bootable / bare-metal est une piste seL4 séparée dans le dépôt. Garder cette frontière nette évite de confondre un build testeur installable avec l’objectif OS à long terme.

Platforms

Plateformes

Windows 10/11 x64, Linux x64, and macOS Apple Silicon are the supported hosts. NVIDIA is recommended on Win/Linux; a CPU path exists in the same artefact when a GPU is absent. Simultaneous multi-user accounts and a complete multi-GPU pipeline are also out of scope — Preview targets a single interactive host session.

Windows 10/11 x64, Linux x64 et macOS Apple Silicon sont les hôtes pris en charge. NVIDIA est recommandé sur Win/Linux ; un chemin CPU existe dans le même artefact sans GPU. Les comptes multi-utilisateur simultanés et un pipeline multi-GPU complet sont aussi hors périmètre — la Preview vise une session hôte interactive unique.

Updates

Mises à jour

When a newer GitHub Release exists, Preview can show a banner and overlay bin/ and share/ without touching var/ or overwriting your etc/*.yaml. Fully automatic apply — download now, apply silently on the next launch — is not finished yet, so you stay in control of when the overlay lands.

Quand une Release GitHub plus récente existe, la Preview peut afficher une bannière et superposer bin/ et share/ sans toucher var/ ni écraser vos etc/*.yaml. L’application pleinement automatique — télécharger maintenant, appliquer silencieusement au prochain lancement — n’est pas terminée : vous gardez la main sur le moment où la superposition arrive.

Modules and UI surface

Modules et surface d’UI

There is no public module marketplace. Install uses a local signed catalogue with capability review. Module UI is a closed declarative widget tree the host paints — not a sandboxed webview or free-form HTML/JS compositor. Widget kinds such as pie, scatter, and webview stay out so the host keeps a fail-closed document shape.

Il n’y a pas de marketplace publique de modules. L’install s’appuie sur un catalogue local signé avec revue de caps. L’UI de module est un arbre de widgets déclaratif fermé que l’hôte peint — pas une webview sandbox ni un compositeur HTML/JS libre. Des kinds comme pie, scatter et webview restent hors pour garder une forme de document fail-closed côté hôte.

Media and voice

Média et voix

Image generation and TTS shipped in 0.8.0. Video generation, speech-to-text, and always-on voice are not in 0.9.0. Img2img and inpaint are not first-class intents yet. A 32B model is not offered in the installer packs; first-run tiers stop at the high pack documented in first-run.

La génération d’image et le TTS sont arrivés en 0.8.0. La génération vidéo, la reconnaissance vocale et la voix always-on ne sont pas dans 0.9.0. Img2img et inpaint ne sont pas encore des intents de premier plan. Un modèle 32B n’est pas proposé dans les packs de l’installateur ; les paliers first-run s’arrêtent au pack high documenté dans first-run.

Providers, messaging, and bridge depth

Providers, messagerie et profondeur du pont

Cloud models go through OpenAI-compatible Providers only — not native Messages, Gemini, or Bedrock APIs. Messaging channels such as Slack or Discord are not in the OS core. The sibling-bridge contract exists as schemas and documentation; a live HTTP sibling daemon and a TPM hardware envelope are not part of this Preview. On the inference side, 0.9 uses prefix replay rather than a llama.cpp KV snapshot API.

Les modèles cloud passent uniquement par des Providers compatibles OpenAI — pas d’API natives Messages, Gemini ou Bedrock. Les canaux de messagerie type Slack ou Discord ne sont pas dans le noyau OS. Le contrat sibling-bridge existe en schémas et documentation ; un daemon HTTP sibling live et une enveloppe matérielle TPM ne font pas partie de cette Preview. Côté inférence, 0.9 utilise le rejeu de préfixe plutôt qu’une API de snapshot KV llama.cpp.
