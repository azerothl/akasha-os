  • Bannière : Preview on Windows/Linux — this is not the bootable OS yet

# walk the paths

# parcourir les chemins

  1. Finish model setup and the 4-step tutorial. Chat offline. Optionally change the session model.
  2. Terminer le réglage des modèles et le tutoriel (4 étapes). Chat hors ligne. Changer éventuellement le modèle de session.
  3. Models tab: installed entries; Download an alternative if offered.
  4. Onglet Models : entrées installées ; Download une alternative si proposée.
  5. Notes: title + body → Create, then List.
  6. Notes : titre + corps → Create, puis List.
  7. Agents: task such as “create a note titled cohort with content hello”.
  8. Agents : tâche du type « create a note titled cohort with content hello ».
  9. Confirmation banner: Deny once, Accept another. Timeout = deny.
  10. Bannière de confirmation : Deny une fois, Accept une autre. Timeout = refus.
  11. Audit → Refresh. Kill aos-auditd; chat continues; supervisor restarts it.
  12. Audit → Refresh. Tuer aos-auditd ; le chat continue ; le superviseur le relance.
  13. Three Chat sessions; restart; histories return.
  14. Trois sessions Chat ; redémarrer ; les historiques reviennent.
  15. Memory: remember a fact, Recall, then use it in Chat.
  16. Memory : remember un fait, Recall, puis l’utiliser dans Chat.
  17. Network off → search fails. Network on → search. Optional download / generate file. See network.
  18. Réseau off → recherche échoue. Réseau on → recherche. Téléchargement / fichier optionnels. Voir network.
  19. Notes: create a note, then read it from the list (after an update, the packaged WASM must match this release).
  20. Notes : créer une note, puis la relire dans la liste (après une update, le WASM empaqueté doit correspondre à cette release).
  21. Troubleshoot (Help): run diagnostics. If findings exist, a GitHub report can open.
  22. Dépannage (Aide) : lancer le diagnostic. S’il y a des anomalies, un rapport GitHub peut s’ouvrir.

# send from the UI

# envoyer depuis l’UI

Feedback tab (or Report): title, category (bug / ux / perf / security), severity, body. Create a GitHub issue is checked by default, except security. Send feedback. A local copy is written under var/feedback/. An issue (or a prefilled GitHub form) opens on azerothl/akasha-os. With a GitHub account, confirm Submit new issue.

Onglet Feedback (ou Report) : titre, catégorie (bug / ux / perf / security), sévérité, corps. Create a GitHub issue est coché par défaut, sauf security. Send feedback. Une copie locale est écrite sous var/feedback/. Une issue (ou un formulaire GitHub prérempli) s’ouvre sur azerothl/akasha-os. Avec un compte GitHub, confirmez Submit new issue.

Security reports are not published. There is no automatic network upload except explicit search, download, and GitHub submit.

Les rapports sécurité ne sont pas publiés. Pas d’upload réseau automatique hors recherche, téléchargement et envoi GitHub explicites.
