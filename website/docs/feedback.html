If you are in the Preview 0.15.0 cohort, this page is the protocol: install without cargo or a clone, exercise the main paths, then send a report from the UI. The same outline lives in the Scenarios tab. Si vous êtes dans la cohorte Preview 0.15.0, cette page est le protocole : installer sans cargo ni clone, exercer les chemins principaux, puis envoyer un rapport depuis l’UI. Le même plan vit dans l’onglet Scenarios.

What we are asking

Ce que nous demandons

You do not need to be exhaustive on day one. Walk the paths you can honestly cover, note what felt clear or broken, and file from Feedback. A partial report with a real setup is more useful than a perfect checklist left empty.

Vous n’avez pas besoin d’être exhaustif dès le premier jour. Parcourez les chemins que vous pouvez couvrir honnêtement, notez ce qui était clair ou cassé, et envoyez depuis Feedback. Un rapport partiel avec une vraie install vaut mieux qu’une checklist parfaite laissée vide.

Before you start

Avant de commencer

You need Windows or Linux x64 (NVIDIA recommended; CPU path OK). Follow install, launch Akasha OS Preview (aos-session), and confirm the banner that this is Preview on Windows/Linux — not the bootable OS yet.

Il faut Windows ou Linux x64 (NVIDIA recommandé ; chemin CPU OK). Suivez install, lancez Akasha OS Preview (aos-session), et confirmez la bannière : Preview on Windows/Linux — pas encore l’OS bootable.

Walk the paths

Parcourir les chemins

Treat the list as a suggested tour rather than a drill sergeant. Skip what your hardware or time cannot support, and say so in the report.

Traitez la liste comme une visite suggérée plutôt qu’un sergent. Sautez ce que votre matériel ou votre temps ne permet pas, et dites-le dans le rapport.

  1. Finish model setup and the 4-step tutorial. Chat offline. Optionally change the session model.
  2. Terminer le réglage des modèles et le tutoriel (4 étapes). Chat hors ligne. Changer éventuellement le modèle de session.
  3. Models tab: installed entries; Download an alternative if offered.
  4. Onglet Models : entrées installées ; Download une alternative si proposée.
  5. Notes: title + body → Create, then List.
  6. Notes : titre + corps → Create, puis List.
  7. Tasks tab: create a task; an agent with tasks.list should see it.
  8. Onglet Tasks : créer une tâche ; un agent avec tasks.list doit la voir.
  9. Agents: task such as “create a note titled cohort with content hello”. Open Detail.
  10. Agents : tâche du type « create a note titled cohort with content hello ». Ouvrir Détail.
  11. Confirmation banner: Deny once, Accept another. Timeout = deny.
  12. Bannière de confirmation : Deny une fois, Accept une autre. Timeout = refus.
  13. Audit → Refresh. Caps: list holder agent:<id>, revoke a non-critical cap. Kill aos-auditd; chat continues; supervisor restarts it.
  14. Audit → Refresh. Caps : lister le détenteur agent:<id>, révoquer une cap non critique. Tuer aos-auditd ; le chat continue ; le superviseur le relance.
  15. Three Chat sessions; restart; histories return.
  16. Trois sessions Chat ; redémarrer ; les historiques reviennent.
  17. Memory: remember a fact, Recall, then use it in Chat.
  18. Memory : remember un fait, Recall, puis l’utiliser dans Chat.
  19. Settings → Secrets: save a key; restart; master.backend is keyring or file (no plaintext master.key on Windows).
  20. Settings → Secrets : enregistrer une clé ; redémarrer ; master.backend est keyring ou file (pas de master.key lisible sous Windows).
  21. Settings → Local module catalogue: Install a listed module (cap review). Stop a streaming chat reply; Copy a message.
  22. Settings → Catalogue local : Installer un module listé (revue de caps). Stop sur une réponse en flux ; Copier un message.
  23. Scenarios (or Chat « create a module »): scaffold / package / install a script module; a Modules sidebar tab appears (not notes / tasks / ext-rt). Open it, submit once.
  24. Scénarios (ou Chat « crée un module ») : scaffolder / packager / installer un module script ; un onglet Modules apparaît (pas notes / tasks / ext-rt). L’ouvrir, soumettre une fois.
  25. Network off → search fails. Network on → search (engine auto). Optional Browse URL / download / generate file. See network.
  26. Réseau off → recherche échoue. Réseau on → recherche (moteur auto). Browse URL / téléchargement / fichier optionnels. Voir network.
  27. Notes: create a note, then read it from the list (after an update, the packaged WASM must match this release).
  28. Notes : créer une note, puis la relire dans la liste (après une update, le WASM empaqueté doit correspondre à cette release).
  29. Troubleshoot (Help): run diagnostics. If findings exist, a GitHub report can open.
  30. Dépannage (Aide) : lancer le diagnostic. S’il y a des anomalies, un rapport GitHub peut s’ouvrir.
  31. 0.8 surfaces: Uninstall a non-bundled module from Settings. Providers: add loopback (works in local_only). Optional Models Download of SD 1.5 / Piper (engine arrives with the pack) then Chat /image / /speak.
  32. Surfaces 0.8 : Désinstaller un module non bundlé depuis Settings. Providers : ajouter un loopback (marche en local_only). Download optionnel SD 1.5 / Piper (le moteur arrive avec le pack) puis Chat /image / /speak.

Send from the UI

Envoyer depuis l’UI

Open the Feedback tab (or Report): title, category (bug / ux / perf / security), severity, and body. Create a GitHub issue is checked by default, except for security. Send feedback writes a local copy under var/feedback/ and opens an issue (or a prefilled GitHub form) on azerothl/akasha-os. With a GitHub account, confirm Submit new issue.

Ouvrez l’onglet Feedback (ou Report) : titre, catégorie (bug / ux / perf / security), sévérité et corps. Create a GitHub issue est coché par défaut, sauf security. Send feedback écrit une copie locale sous var/feedback/ et ouvre une issue (ou un formulaire GitHub prérempli) sur azerothl/akasha-os. Avec un compte GitHub, confirmez Submit new issue.

Security reports are not published. There is no automatic network upload except explicit search, download, and GitHub submit.

Les rapports sécurité ne sont pas publiés. Pas d’upload réseau automatique hors recherche, téléchargement et envoi GitHub explicites.
