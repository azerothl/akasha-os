The LAN cluster is experimental and disabled by default in Preview 0.17.0. It uses only nodes you add and explicitly pair — never Internet peers. Le cluster LAN est expérimental et désactivé par défaut dans la Preview 0.17.0. Il utilise uniquement les nœuds que vous ajoutez puis appairez — jamais des pairs Internet.

Not the same as Allow network

Distinct de Allow network

Sidebar Allow network controls WAN egress for search and fetch. The LAN cluster is a separate opt-in coordinator inside aos-modeld for paired LAN workers. See network for offline-by-default egress.

Allow network dans la barre latérale contrôle la sortie WAN pour recherche et fetch. Le cluster LAN est un coordinateur opt-in distinct dans aos-modeld pour des workers LAN appairés. Voir network pour le hors-ligne par défaut.

Enable and pair

Activer et appairer

Settings → Models → LAN cluster. Set local node id, listener address, and session-key secret name (default lan_cluster_session_key). Store a 64-hex character key in Settings → Secrets vault. Add remote nodes by fingerprint; pair after verification. Inventory: var/run/lan-pairing.json.

Paramètres → Modèles → Cluster LAN. Renseignez l’id nœud local, l’adresse d’écoute et le nom du secret de session (défaut lan_cluster_session_key). Enregistrez une clé 64 caractères hex dans Paramètres → Coffre à secrets. Ajoutez les nœuds distants par empreinte ; appairez après vérification. Inventaire : var/run/lan-pairing.json.
