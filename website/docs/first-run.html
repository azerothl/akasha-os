After install, the first launch of Preview 0.9.0 picks a model pack for your machine, then opens a short in-app tutorial. This is still a host app on Windows or Linux — not a bootable OS. Après install, le premier lancement de la Preview 0.9.0 choisit un pack de modèles pour votre machine, puis ouvre un court tutoriel in-app. C’est toujours une appli hôte sur Windows ou Linux — pas un OS bootable.

Before you launch

Avant de lancer

Prefer an NVIDIA driver that answers nvidia-smi -L, or plan to use the CPU path in Settings → Inference. About 8 GB free disk helps for the mid-tier pack (less for cpu). Launch via install.cmd / install.sh, or run bin/aos-session directly.

Préférez un pilote NVIDIA qui répond à nvidia-smi -L, ou prévoyez le chemin CPU dans Settings → Inference. Environ 8 Go libres aident pour le pack mid (moins pour cpu). Lancez via install.cmd / install.sh, ou exécutez bin/aos-session directement.

Model setup

Réglage des modèles

On first launch — when var/models/installed.json does not exist yet — aos-session probes GPU VRAM, RAM, and disk into var/run/hardware.json, then opens Model selection with an auto-best suggestion for your tier.

Au premier lancement — quand var/models/installed.json n’existe pas encore — aos-session sonde VRAM GPU, RAM et disque dans var/run/hardware.json, puis ouvre Model selection avec une suggestion auto-meilleure pour votre palier.

  • cpu (no NVIDIA) → Qwen3.5-4B + Embedding 0.6B
  • cpu (sans NVIDIA) → Qwen3.5-4B + Embedding 0.6B
  • low (<10 GiB VRAM) → Qwen3.5-4B + Embedding 0.6B
  • low (<10 Gio VRAM) → Qwen3.5-4B + Embedding 0.6B
  • mid (10–20 GiB, e.g. RTX 4080 SUPER) → Qwen3.5-9B + Embedding 0.6B
  • mid (10–20 Gio, ex. RTX 4080 SUPER) → Qwen3.5-9B + Embedding 0.6B
  • high (≥20 GiB) → Qwen3 30B-A3B + Embedding 0.6B
  • high (≥20 Gio) → Qwen3 30B-A3B + Embedding 0.6B

Confirm the suggestion, or pick alternatives. GGUFs download into share/models/. The catalogue is share/models/catalog-offerings.json; the registry is var/models/installed.json. Services start, egui opens, and the four-step tutorial begins. Expect a banner that says this is Preview on Windows/Linux — not the bootable OS yet.

Confirmez la suggestion, ou choisissez des alternatives. Les GGUF descendent dans share/models/. Le catalogue est share/models/catalog-offerings.json ; le registre est var/models/installed.json. Les services démarrent, egui s’ouvre, et le tutoriel en quatre étapes commence. Attendez-vous à une bannière qui dit que c’est une Preview sur Windows/Linux — pas encore l’OS bootable.

The tutorial walkthrough

Le parcours du tutoriel

The in-app tutorial is four short steps meant to prove that the host answers offline after models are ready. Stay with it until it finishes; then explore Chat and the other tabs at your own pace. Network stays off unless you later choose Allow network.

Le tutoriel in-app compte quatre courtes étapes pour montrer que l’hôte répond hors ligne une fois les modèles prêts. Suivez-le jusqu’au bout ; puis explorez Chat et les autres onglets à votre rythme. Le réseau reste éteint tant que vous n’activez pas Allow network plus tard.

If setup is cancelled

Si le réglage est annulé

Delete nothing. Relaunch to reopen model selection. Without a GPU, the slower CPU pack is available in the same zip via Settings → Inference; NVIDIA remains recommended. Daemon logs live under var/run/*.stderr.log (Troubleshooting button).

Ne supprimez rien. Relancez pour rouvrir la sélection de modèles. Sans GPU, le pack CPU plus lent est disponible dans le même zip via Settings → Inference ; NVIDIA reste recommandé. Les journaux des daemons sont sous var/run/*.stderr.log (bouton Troubleshooting).

Closing the UI

Fermer l’UI

Closing the Preview window stops the daemons that aos-session started for that run. Your var/ data stays on disk for the next launch.

Fermer la fenêtre Preview arrête les daemons que aos-session a démarrés pour ce run. Vos données var/ restent sur le disque pour le prochain lancement.

Later model updates

Mises à jour de modèles plus tard

If catalog-offerings.json recommends models you do not have, a banner appears → Open Models → Download. Media packs also fetch sd.cpp / piper into bin/ when missing. Restart Preview after download so etc/modeld.yaml picks up new paths. CLI: aos-session --download-models <id>…

Si catalog-offerings.json recommande des modèles absents, une bannière apparaît → Open Models → Download. Les packs média tirent aussi sd.cpp / piper dans bin/ s’ils manquent. Redémarrez Preview après le téléchargement pour que etc/modeld.yaml voie les nouveaux chemins. CLI : aos-session --download-models <id>…
