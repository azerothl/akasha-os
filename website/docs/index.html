A short manual for Preview 0.17.0 — the installable host app on Windows, Linux, or Mac (Apple Silicon). It walks you from download through first chat, network choices, and cohort feedback, without asking you to read the kernel specs. Un manuel court pour la Preview 0.17.0 — l’appli hôte installable sur Windows, Linux ou Mac (Apple Silicon). Il vous mène du téléchargement au premier chat, aux choix réseau et au retour de cohorte, sans vous demander de lire les specs noyau.

Preview is not a bootable OS. You need Windows or Linux x64, or macOS on Apple Silicon (not Intel Mac). NVIDIA is recommended on Win/Linux; a slower CPU path ships in the same archive. Releases need no cargo; the build chapter is for people who compile from source. Specs, ADRs, and the seL4 track stay in the repository. Cohort hangout: community.

La Preview n’est pas un OS bootable. Il faut Windows ou Linux x64, ou macOS Apple Silicon (pas Intel Mac). NVIDIA est recommandé sous Win/Linux ; un chemin CPU plus lent est dans la même archive. Les Releases n’exigent pas cargo ; le chapitre build s’adresse à qui compile depuis les sources. Specs, ADR et piste seL4 restent dans le dépôt. Lieu de rencontre de la cohorte : community.
