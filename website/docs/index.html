A short manual for Preview 0.9.0 — the installable host app on Windows or Linux. It walks you from download through first chat, network choices, and cohort feedback, without asking you to read the kernel specs. Un manuel court pour la Preview 0.9.0 — l’appli hôte installable sur Windows ou Linux. Il vous mène du téléchargement au premier chat, aux choix réseau et au retour de cohorte, sans vous demander de lire les specs noyau.

Preview is not a bootable OS. You need Windows or Linux x64. NVIDIA is recommended; a slower CPU path ships in the same archive. Releases need no cargo; the build chapter is for people who compile from source. Specs, ADRs, and the seL4 track stay in the repository.

La Preview n’est pas un OS bootable. Il faut Windows ou Linux x64. NVIDIA est recommandé ; un chemin CPU plus lent est dans la même archive. Les Releases n’exigent pas cargo ; le chapitre build s’adresse à qui compile depuis les sources. Specs, ADR et piste seL4 restent dans le dépôt.

Where to begin

Par où commencer

Most testers start at install, stay with first-run until the tutorial is done, then skim use and feedback if they are in the Preview cohort. The what's new log is useful when you already know the host and want this version’s deltas.

La plupart des testeurs commencent par install, restent sur first-run jusqu’à la fin du tutoriel, puis parcourent use et feedback s’ils sont dans la cohorte Preview. Le journal nouveauté sert quand on connaît déjà l’hôte et veut les deltas de cette version.
