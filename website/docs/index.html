User manual for Preview 0.1.2. Written for someone who will install the host app, finish the tutorial, and send feedback from the UI — not for someone who wants to read the kernel specs. Manuel utilisateur de la Preview 0.1.2. Pour quelqu’un qui installe l’appli hôte, termine le tutoriel et envoie un retour depuis l’UI — pas pour lire les specs noyau.

This is not a bootable OS. You need Windows or Linux x64 and an NVIDIA GPU. No cargo. Specs, ADRs, and the seL4 track stay in the repository.

Ce n’est pas un OS bootable. Il faut Windows ou Linux x64 et un GPU NVIDIA. Pas de cargo. Specs, ADR et piste seL4 restent dans le dépôt.
