Using Preview 0.11.0 Utiliser la Preview 0.11.0

Not a bootable OS

Pas un OS bootable

Preview is a host app on Windows or Linux. Closing the UI stops the daemons. This chapter covers the shipped surfaces after first run and the four-step tutorial. The full catalogue lives in FEATURES.md.

La Preview est une appli hôte sur Windows ou Linux. Fermer l’UI arrête les daemons. Ce chapitre couvre les surfaces livrées après first-run et le tutoriel en quatre étapes. Le catalogue complet est dans FEATURES.md.

Intro

Intro

After install and model setup, egui opens with Chat and a sidebar of grants: Sessions, Models, Memory, Notes, Tasks, Modules (when you install declarative packages), Agents, Caps, Audit, Providers, Settings, Network, Image studio, Feedback, and Scenarios. Each section below is how to operate one of those surfaces. Prefer the local model offline; turn on network only when you mean to search, browse, or fetch.

Après install et réglage des modèles, egui ouvre Chat et une barre latérale de grants : Sessions, Models, Memory, Notes, Tasks, Modules (quand vous installez des paquets déclaratifs), Agents, Caps, Audit, Providers, Settings, Network, studio Image, Feedback et Scénarios. Chaque section ci-dessous explique une de ces surfaces. Préférez le modèle local hors ligne ; n’activez le réseau que pour chercher, parcourir ou télécharger.

Chat / Sessions

Chat / Sessions

Parallel conversations persist across restart. Each session keeps its own history and can pick its own model from the combo (fallback: the default instruct model). Streaming replies come from the local backend when routing is local_only; once GGUFs are on disk, chat works with Allow network off. Stop cancels the in-flight model.infer; Copy puts a message (or Troubleshoot body) on the clipboard. Before infer, Preview injects mem.context (session hits, user facts, and product-doc RAG chunks from FEATURES / STATUS / TESTER). User and assistant messages use distinct bubbles. Background agents attached via /agent or assistant delegation show as cards in the thread.

Les conversations parallèles survivent au redémarrage. Chaque session garde son historique et peut choisir son modèle dans le combo (sinon le modèle instruct par défaut). Les réponses en flux viennent du backend local quand le routage est local_only ; une fois les GGUF sur disque, le chat marche avec Allow network éteint. Stop annule le model.infer en cours ; Copier met un message (ou le corps Troubleshoot) dans le presse-papiers. Avant l’inférence, la Preview injecte mem.context (hits de session, faits utilisateur, et chunks RAG produit depuis FEATURES / STATUS / TESTER). Les messages user et assistant ont des bulles distinctes. Les agents de fond via /agent ou délégation apparaissent en cartes dans le fil.

Slash commands (popup above the input with /): /commands, /help (system snapshot), /agent <task>, /notes, /notenew, /notesearch, /audit [n], /kill / /pause, /image <prompt>, and /speak <text>. Chat « crée un module … » (or “create a module”) launches a scaffold agent. Markdown renders agent actions in the thread.

Commandes slash (popup au-dessus de la saisie avec /) : /commands, /help (instantané système), /agent <tâche>, /notes, /notenew, /notesearch, /audit [n], /kill / /pause, /image <prompt> et /speak <texte>. Le chat « crée un module … » lance un agent de scaffold. Le markdown affiche les actions d’agent dans le fil.

Create three sessions, chat in each, restart Preview: histories must reappear. That is the cohort check for session persistence.

Créez trois sessions, parlez dans chacune, redémarrez Preview : les historiques doivent réapparaître. C’est le contrôle de persistance de session pour la cohorte.

Models

Models

The Models tab lists installed offerings, loads them, and downloads alternatives from share/models/catalog-offerings.json into share/models/. Live metrics (TTFT, tok/s, VRAM / RAM / disk) appear in the sidebar and on this tab. A green banner appears when newer packs fit your detected VRAM tier. After a download, restart so etc/modeld.yaml sees new paths. CLI: aos-session --download-models <id>….

L’onglet Models liste les offres installées, les charge et télécharge des alternatives depuis share/models/catalog-offerings.json vers share/models/. Des métriques live (TTFT, tok/s, VRAM / RAM / disque) apparaissent dans la barre latérale et ici. Une bannière verte s’affiche quand de nouvelles offres tiennent dans votre palier VRAM. Après un téléchargement, redémarrez pour que etc/modeld.yaml voie les chemins. CLI : aos-session --download-models <id>….

Optional image and TTS packs (for example local:sd-v1-5, Piper en_US / fr_FR, plus Flux2-class, Ideogram4-class, Piper en_GB in 0.9.0) are not in the zip; first-run does not pull them. Download also fetches bin/sd / bin/piper (and sidecars via extra_files) if missing. Settings / Models pick the default image pack and Piper voice; honor them after restart. Without weights or engine, Preview writes a visible stub PNG or short WAV so the pipeline stays testable.

Les packs image et TTS optionnels (par ex. local:sd-v1-5, Piper en_US / fr_FR, plus Flux2-class, Ideogram4-class, Piper en_GB en 0.9.0) ne sont pas dans le zip ; le first-run ne les tire pas. Download installe aussi bin/sd / bin/piper (et les sidecars via extra_files) s’ils manquent. Settings / Models choisissent le pack image et la voix Piper par défaut ; honorez-les après redémarrage. Sans poids ou moteur, la Preview écrit un PNG stub visible ou un court WAV pour garder le pipeline testable.

Mid-token migrate (0.9.0): Settings Inference auto / gpu / cpu calls model.migrate so a live completion continues on the same stream — no Stop, no cancelled turn. On NVIDIA, the cpu pin stays on the CUDA aos-modeld with n_gpu_layers = 0. Fail-closed fallback is the older cancel-and-restart path (audited).

Migrate mid-token (0.9.0) : Settings Inférence auto / gpu / cpu appelle model.migrate pour que la complétion live continue sur le même flux — pas de Stop, pas de tour annulé. Sur NVIDIA, le pin cpu reste sur aos-modeld CUDA avec n_gpu_layers = 0. Le repli fail-closed est l’ancien chemin cancel + restart (audité).

Memory

Memory

Long-term user facts: Remember / Recall / list / edit / delete in the Memory tab. Typed relations similar, updates, and supersedes auto-link on close remembers. Session and user hits assemble as mem.context for chat and agents. Agents also use episodic memory and memory.remember / memory.recall. Bootstrap is memory-first: task.assess then structured mem.bootstrap (active facts and similar neighbors; superseded omitted).

Faits utilisateur long terme : Remember / Recall / lister / éditer / supprimer dans l’onglet Memory. Les relations typées similar, updates et supersedes se lient automatiquement. Hits de session et utilisateur forment mem.context pour le chat et les agents. Les agents ont aussi une mémoire épisodique et memory.remember / memory.recall. Le bootstrap est memory-first : task.assess puis mem.bootstrap structuré (faits actifs et voisins similaires ; les supersédés sont omis).

Auto-remember from chat (Settings, on by default): after each turn, low-priority mem.extract proposes durable facts → mem.user.remember with source=chat. Secrets (API keys, tokens, IBAN-like) are never auto-stored (audited). The Memory list shows a [chat] badge on extracted facts. Extraction is non-blocking and skips if a previous extract is still running.

Mémorisation auto depuis le chat (Settings, activée par défaut) : après chaque tour, un mem.extract basse priorité propose des faits durables → mem.user.remember avec source=chat. Les secrets (clés API, tokens, IBAN-like) ne sont jamais auto-stockés (audité). La liste Memory affiche un badge [chat] sur les faits extraits. L’extraction est non bloquante et saute si une extraction précédente tourne encore.

Notes

Notes

Dual-surface WASM module (notes.aospkg). Human UI: title + body → Create, then List / search. Agent tools: notes.create, notes.update, notes.search, and related intents. Same data for humans and agents. On boot, share/modules/notes.aospkg is copied to var/modules/notes when the manifest hash or WASM fingerprint differs, so a Preview update does not keep a stale module. notes.read accepts title, name, path, or slug. Via agent: Agents tab or Chat /agent with a task such as “create a note titled cohort with content hello”.

Module WASM dual-surface (notes.aospkg). UI humaine : titre + corps → Create, puis List / search. Outils agent : notes.create, notes.update, notes.search, et intents liés. Les mêmes données pour humains et agents. Au boot, share/modules/notes.aospkg est recopié vers var/modules/notes si le hash manifest ou l’empreinte WASM diffère, pour qu’une update Preview ne garde pas un module périmé. notes.read accepte title, name, path ou slug. Via agent : onglet Agents ou Chat /agent avec une tâche du type « create a note titled cohort with content hello ».

Tasks

Tasks

Dual-surface WASM module (tasks.aospkg). Human UI: create / list / complete. Agent tools: tasks.create, tasks.list, tasks.update, tasks.complete. Same JSON store under /documents/tasks/tasks.json. Resyncs on boot like notes. Skill tasks ships under share/skills/.

Module WASM dual-surface (tasks.aospkg). UI humaine : créer / lister / terminer. Outils agent : tasks.create, tasks.list, tasks.update, tasks.complete. Même store JSON sous /documents/tasks/tasks.json. Resync au boot comme notes. La skill tasks est livrée sous share/skills/.

Modules (declarative_ui)

Modules (declarative_ui)

Installed packages with ui.mode=declarative_ui get a dynamic sidebar tab under Modules. Notes, Tasks, and ext-rt stay hardcoded and are excluded from dynamic tabs. The host paints a closed widget tree from ui/index.html — no webview, no free HTML/JS UI. Widgets include column / row, heading, text, markdown, stat_row, table, line_chart, form (JSON Schema), button, select / radio / checkbox / textarea, bar_chart, image, and audio.

Les paquets installés avec ui.mode=declarative_ui obtiennent un onglet dynamique sous Modules. Notes, Tasks et ext-rt restent en dur et sont exclus des onglets dynamiques. L’hôte peint un arbre de widgets fermé depuis ui/index.html — pas de webview, pas d’UI HTML/JS libre. Widgets : column / row, heading, text, markdown, stat_row, table, line_chart, form (JSON Schema), button, select / radio / checkbox / textarea, bar_chart, image et audio.

Intent module.ui validates the document fail-closed; invalid ui/index.html shows an error banner (no partial widgets). Button and form submits use the same cap review as module.invoke. Install still requires confirmation; refuse → quarantine. Settings lists the local signed catalogue and can uninstall non-bundled modules (not notes / tasks / ext-rt).

L’intent module.ui valide le document en fail-closed ; un ui/index.html invalide affiche une bannière (pas de widgets partiels). Soumissions bouton / formulaire : même revue de caps que module.invoke. L’install exige encore une confirmation ; refus → quarantaine. Settings liste le catalogue local signé et peut désinstaller les modules non bundle (pas notes / tasks / ext-rt).

Agents

Agents

Observe / Think / Act with capability checks, confirmation, and audit. Create an agent with a task and a model (or /agent <task> from Chat). Goal loop: goal.complete / goal.fail; max steps and timeout come from Settings defaults. task.assess classifies simple vs complex; complex activates the planner skill. Shipped skills: notes-writer, research, file-author, planner, tasks. Tools may be native, WASM module, MCP, or runtime (plan / spawn / memory). Sub-agents: agent.spawn / agent.await. Mid-task user.ask pauses in the linked chat (Blocked) until the next reply (FIFO; 10 min timeout).

Observe / Think / Act avec contrôles de caps, confirmation et audit. Créez un agent avec une tâche et un modèle (ou /agent <tâche> depuis Chat). Boucle de goal : goal.complete / goal.fail ; max steps et timeout depuis Settings. task.assess classe simple vs complexe ; le complexe active la skill planner. Skills livrées : notes-writer, research, file-author, planner, tasks. Outils : natifs, module WASM, MCP ou runtime (plan / spawn / mémoire). Sous-agents : agent.spawn / agent.await. user.ask en cours de tâche met en pause dans le chat lié (Blocked) jusqu’à la prochaine réponse (FIFO ; timeout 10 min).

Sensitive actions raise a blocking confirmation banner; Deny once, Accept another; timeout = deny (fail-closed). Open Detail (Agents tab or chat card) for live state, step n/max, tokens, duration, simple/complex badge, skills and MCP servers, parent / children, Sources (web / document / fetch), and the step timeline (agent.trace). Controls: Pause, Resume, Retry, Kill, Steer. Schedules (schedule.create / list / cancel) live under Settings; ticker min interval 30s; persist in var/schedules/.

Une action sensible affiche une bannière de confirmation ; Deny une fois, Accept une autre ; timeout = refus (fail-closed). Ouvrez Détail (onglet Agents ou carte chat) pour l’état live, step n/max, tokens, durée, badge simple/complexe, skills et serveurs MCP, parent / enfants, Sources (web / document / fetch) et la timeline (agent.trace). Contrôles : Pause, Reprendre, Retry, Kill, Steer. Les schedules (schedule.create / list / cancel) sont dans Settings ; intervalle min 30 s ; persistance dans var/schedules/.

Caps

Caps

Caps tab: list capabilities by holder (cap.list) and revoke (audited). Hot-grant via cap.request still requires trust plus confirmation. Module install and tool invoke paths go through the same review surface — nothing auto-approves a new package.

Onglet Caps : lister les capacités par détenteur (cap.list) et révoquer (audité). Le hot-grant via cap.request exige toujours trust plus confirmation. Install de module et invoke d’outil passent par la même revue — rien n’auto-approuve un nouveau paquet.

Audit

Audit

Append-only hashed journal of signed events. Audit tab → Refresh. Kill aos-auditd: chat must continue; the supervisor restarts auditd in the background. Slash /audit [n] shows the last n events in Chat.

Journal hashé append-only d’événements signés. Onglet Audit → Refresh. Tuer aos-auditd : le chat doit continuer ; le superviseur relance auditd en arrière-plan. Slash /audit [n] montre les n derniers événements dans Chat.

Providers

Providers

Providers tab: add / list / test / remove OpenAI-compatible cloud endpoints and loopback (Ollama / vLLM / LM Studio). API keys live in the encrypted vault, never in the provider file. Chat combo groups local vs provider. Routing local_only (default) still allows loopback; WAN cloud needs balanced plus Allow network. Infer with secret data stays local. Native Messages / Gemini / Bedrock APIs are not shipped — OpenAI-compat only.

Onglet Providers : ajouter / lister / tester / retirer des endpoints cloud OpenAI-compat et loopback (Ollama / vLLM / LM Studio). Les clés API vivent dans le vault chiffré, jamais dans le fichier provider. Le combo Chat groupe local vs provider. Le routage local_only (défaut) autorise encore le loopback ; le cloud WAN exige balanced plus Allow network. L’inférence avec données secret reste locale. Pas d’API natives Messages / Gemini / Bedrock — OpenAI-compat seulement.

Settings

Settings

Preferences persist in var/run/preferences.json (migrated from onboarding.json if needed). Groups: language en / fr; default trust low / medium; Inference auto / gpu / cpu (mid-token migrate in 0.9.0); routing local_only / balanced; Allow network (same as sidebar); Auto-remember from chat; agent default model, max steps (1–128), timeout (60–86400 s); schedules; Secrets vault (Brave / GitHub / OpenAI keys — master key in OS keyring, file 0600 fallback with AOS_SECRETS_FILE_KEY=1); local signed module catalogue Install / Uninstall; Web search engine, browse max chars, fetch max bytes; default image pack and Piper voice.

Les préférences persistent dans var/run/preferences.json (migrées depuis onboarding.json si besoin). Groupes : langue en / fr ; trust défaut low / medium ; Inférence auto / gpu / cpu (migrate mid-token en 0.9.0) ; routage local_only / balanced ; Allow network (idem barre latérale) ; mémorisation auto ; modèle agent, max steps (1–128), timeout (60–86400 s) ; schedules ; vault Secrets (clés Brave / GitHub / OpenAI — clé maître dans le keyring OS, repli fichier 0600 avec AOS_SECRETS_FILE_KEY=1) ; catalogue local de modules Install / Uninstall ; Web (moteur, max chars browse, max bytes fetch) ; pack image et voix Piper par défaut.

Network

Network

Default mode is offline_strict (deny-by-default egress). Enable Allow network in the sidebar or Settings before search, browse, or fetch. Intents: web.search (engine auto = Brave → DuckDuckGo → Bing, or force one), web.browse (HTML → plain text, no JavaScript), net.fetch (URL into the logical FS, default /downloads/), and files.generate (md / txt / json / csv / png / pdf). Without a Brave key, auto falls through to DuckDuckGo then Bing HTML. Optional keys live under Settings → Secrets.

Mode défaut : offline_strict (egress deny-by-default). Activez Allow network dans la barre latérale ou Settings avant recherche, browse ou fetch. Intents : web.search (moteur auto = Brave → DuckDuckGo → Bing, ou forcer un), web.browse (HTML → texte, pas de JavaScript), net.fetch (URL dans le FS logique, défaut /downloads/), et files.generate (md / txt / json / csv / png / pdf). Sans clé Brave, auto bascule sur DuckDuckGo puis Bing HTML. Clés optionnelles sous Settings → Secrets.

Step-by-step prove-deny then allow is in the next chapter: Network.

La procédure prouver-le-refus puis autoriser est dans le chapitre suivant : Network.

Image Studio & TTS

Studio Image & TTS

Intents media.image.generate / media.audio.generate write PNG / WAV under /downloads; cap media.generate; audited. Options are a closed deny_unknown_fields object (size, steps, CFG, seed, sampler, negative, Piper knobs). Unknown keys are refused and audited; aos-sd maps only allowlisted flags — never a free-form argv string. Placement Manager treats media weights as evictable shards vs the loaded LLM.

Les intents media.image.generate / media.audio.generate écrivent PNG / WAV sous /downloads ; cap media.generate ; audité. Les options sont un objet fermé deny_unknown_fields (taille, steps, CFG, seed, sampler, negative, knobs Piper). Les clés inconnues sont refusées et auditées ; aos-sd ne mappe que des flags allowlistés — jamais une chaîne argv libre. Le Placement Manager traite les poids média comme shards évincables face au LLM chargé.

Image studio tab: prompt, size, steps, CFG, seed, sampler, catalogue style / LoRA / VAE, composition canvas, upscale, and history (reload prompt / composition from PNG sidecars). From Chat, a generated PNG offers Open in studio. Slash /image shows the PNG in the thread. Slash /speak opens an in-chat TTS card (voice + knobs) then Generate; agents may still call the audio intent directly. Download media packs from Models first (engine arrives with the pack).

Onglet studio Image : prompt, taille, steps, CFG, seed, sampler, style / LoRA / VAE du catalogue, canvas composition, upscale et historique (recharge prompt / composition depuis les sidecars PNG). Depuis Chat, un PNG généré propose Ouvrir dans le studio. Slash /image affiche le PNG dans le fil. Slash /speak ouvre une carte TTS (voix + knobs) puis Generate ; les agents peuvent encore appeler l’intent audio directement. Téléchargez d’abord les packs média dans Models (le moteur arrive avec le pack).

Not in Preview 0.11.0: video generation, STT / always-on voice, img2img / inpaint as first-class intents.

Hors Preview 0.11.0 : génération vidéo, STT / voix always-on, img2img / inpaint comme intents de premier plan.

Extend Preview

Étendre la Preview

Preview is meant to be extended on the host without waiting for a bootable image. The extension surfaces below are what ships in 0.9.0.

La Preview est faite pour être étendue sur l’hôte sans attendre une image bootable. Les surfaces ci-dessous sont celles livrées en 0.9.0.

Dual-surface WASM modules

Modules WASM dual-surface

A module is a sandboxed WASM package (wasmtime) with tools humans and agents share. Notes and Tasks are the bundled examples: same store, human tab, agent intents. Scripted packages go through ext-rt (module.scaffold / module.package) then install with cap review.

Un module est un paquet WASM sandboxed (wasmtime) dont les outils sont partagés humains / agents. Notes et Tasks sont les exemples bundle : même store, onglet humain, intents agent. Les paquets scriptés passent par ext-rt (module.scaffold / module.package) puis install avec revue de caps.

declarative_ui (no webview)

declarative_ui (pas de webview)

Set ui.mode=declarative_ui and ship a closed widget tree in ui/index.html. The host validates via module.ui and paints egui widgets — there is no sandboxed HTML/JS compositor in Preview. Schema export: docs/bridge/aos-proto-decl-ui.json. Optional ui JSON on module.scaffold; package / compile copy a real tree (default: heading + form + table on the primary tool).

Réglez ui.mode=declarative_ui et livrez un arbre de widgets fermé dans ui/index.html. L’hôte valide via module.ui et peint des widgets egui — pas de compositeur HTML/JS sandboxé en Preview. Schéma : docs/bridge/aos-proto-decl-ui.json. Champ ui JSON optionnel sur module.scaffold ; package / compile copient un vrai arbre (défaut : heading + form + table sur l’outil principal).

Scaffold / package / install

Scaffold / package / install

From Chat, ask « crée un module … » (or “create a module”) — the host launches an agent (fallback if the model dumps UI JSON instead of agent.spawn). Scenarios can launch the same scaffold → package → install path for a script module. Settings Install reads the local signed catalogue (share/modules/catalogue.yaml + ed25519); hash check on install.

Depuis Chat, demandez « crée un module … » — l’hôte lance un agent (filet si le modèle dump du JSON d’UI au lieu de agent.spawn). Scénarios peut lancer le même chemin scaffold → package → install pour un module script. Settings Install lit le catalogue local signé (share/modules/catalogue.yaml + ed25519) ; contrôle de hash à l’install.

Skills

Skills

Declarative recipes under share/skills/, overridable under var/skills/. Agents load them by name; authoring also exposes skill.create. Start from the five shipped skills before adding your own.

Recettes déclaratives sous share/skills/, surchargeables sous var/skills/. Les agents les chargent par nom ; l’authoring expose aussi skill.create. Partez des cinq skills livrées avant d’en ajouter.

MCP stdio

MCP stdio

Copy share/mcp/servers.yaml.example, add stdio servers, and reference vault secrets with ${secret:name}. MCP tools appear in the agent Detail panel alongside native and module tools.

Copiez share/mcp/servers.yaml.example, ajoutez des serveurs stdio, et référencez les secrets du vault avec ${secret:name}. Les outils MCP apparaissent dans le panneau Détail de l’agent à côté des outils natifs et modules.

Providers as extension

Providers comme extension

Beyond local GGUF, add OpenAI-compat cloud or loopback providers from the Providers tab. Keys stay in the vault. Loopback works under local_only; remote cloud needs balanced routing and network grant.

Au-delà des GGUF locaux, ajoutez des providers cloud OpenAI-compat ou loopback depuis l’onglet Providers. Les clés restent dans le vault. Le loopback marche sous local_only ; le cloud distant exige le routage balanced et le grant réseau.

Not available yet

Pas encore disponible

No public module marketplace (local signed catalogue only). No free HTML/JS module UI or sandboxed webview (closed declarative_ui widget tree only). Also out of Preview: bootable / bare-metal image, macOS, messaging channels, multi-user accounts, complete multi-GPU pipeline, live HTTP sibling daemon, TPM hardware envelope, pie / scatter / webview widget kinds.

Pas de marketplace publique de modules (catalogue local signé seulement). Pas d’UI module HTML/JS libre ni de webview sandboxée (arbre declarative_ui fermé seulement). Aussi hors Preview : image bootable / bare-metal, macOS, canaux de messagerie, multi-utilisateur, pipeline multi-GPU complet, daemon sibling HTTP live, enveloppe TPM matérielle, widgets pie / scatter / webview.

Full shipped catalogue: docs/FEATURES.md on GitHub. Feedback and cohort protocol: feedback. What Preview will not do: limits.

Catalogue livré complet : docs/FEATURES.md sur GitHub. Feedback et protocole de cohorte : feedback. Ce que la Preview ne fera pas : limits.
