# chat

# chat

Ask a question (for example “What is Akasha OS?”). A streamed reply must work with network off once models are on disk. Optionally change the session model combo. Create three sessions, chat in each, restart Preview: histories must reappear.

Posez une question (par exemple « Qu’est-ce qu’Akasha OS ? »). Une réponse en flux doit marcher sans réseau une fois les modèles sur disque. Changez éventuellement le modèle de session. Créez trois sessions, parlez dans chacune, redémarrez Preview : les historiques doivent réapparaître.

# models

# models

Open Models to see installed entries. Download an alternative if offered. A “Models: …” banner appears when newer offerings fit your VRAM tier. After a download, restart so etc/modeld.yaml sees new paths.

Ouvrez Models pour voir les entrées installées. Téléchargez une alternative si elle est proposée. Une bannière « Models: … » apparaît quand de nouvelles offres tiennent dans votre palier VRAM. Après un téléchargement, redémarrez pour que etc/modeld.yaml voie les chemins.

# memory

# memory

Remember a fact (“I prefer French”), then Recall. Back in Chat, the next message should be able to use that context (mem.context injection before infer).

Remember un fait (« je préfère le français »), puis Recall. De retour dans Chat, le message suivant doit pouvoir s’en servir (injection mem.context avant l’inférence).

# notes

# notes

Notes tab: title + body → Create, then List. To create a note via agent: Agents tab → a task like “create a note titled cohort with content hello”. The agent uses the TOOL: convention.

Onglet Notes : titre + corps → Create, puis List. Via agent : onglet Agents → une tâche du type « create a note titled cohort with content hello ». L’agent utilise la convention TOOL:.

# agents

# agents

Create an agent with a task and a model. Preview skills: notes-writer, research, file-author, planner. Optional MCP: copy share/mcp/servers.yaml.example and add stdio servers. Sensitive actions raise a confirmation banner. Deny once, Accept another. Timeout is deny.

Créez un agent avec une tâche et un modèle. Skills Preview : notes-writer, research, file-author, planner. MCP optionnel : copiez share/mcp/servers.yaml.example et ajoutez des serveurs stdio. Une action sensible affiche une bannière. Deny une fois, Accept une autre. Timeout = refus.

# audit

Audit tab → Refresh (signed events). Kill aos-auditd: chat must continue; the supervisor restarts auditd in the background.

Onglet Audit → Refresh (événements signés). Tuer aos-auditd : le chat doit continuer ; le superviseur relance auditd en arrière-plan.
