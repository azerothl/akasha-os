chat

chat

Ask a question (for example “What is Akasha OS?”). A streamed reply must work with network off once models are on disk. Optionally change the session model combo. Stop interrupts generation; Copy puts a message on the clipboard. Create three sessions, chat in each, restart Preview: histories must reappear. Slash /agent <task> (or « crée un module … ») launches a background agent with a card in the thread. /image and /speak write PNG/WAV after you download the optional media packs from Models (the engine is fetched with the pack).

Posez une question (par exemple « Qu’est-ce qu’Akasha OS ? »). Une réponse en flux doit marcher sans réseau une fois les modèles sur disque. Changez éventuellement le modèle de session. Stop interrompt la génération ; Copier met le message dans le presse-papiers. Créez trois sessions, parlez dans chacune, redémarrez Preview : les historiques doivent réapparaître. Slash /agent <tâche> (ou « crée un module … ») lance un agent en fond avec une carte dans le fil. /image et /speak écrivent PNG/WAV après téléchargement des packs média dans Models (le moteur arrive avec le pack).

models

models

Open Models to see installed entries. Download an alternative if offered. Optional image/TTS packs (Stable Diffusion 1.5, Piper) are not in the zip; Download also installs bin/sd / bin/piper if missing. A “Models: …” banner appears when newer offerings fit your VRAM tier. After a download, restart so etc/modeld.yaml sees new paths.

Ouvrez Models pour voir les entrées installées. Téléchargez une alternative si elle est proposée. Les packs image/TTS (Stable Diffusion 1.5, Piper) ne sont pas dans le zip ; Download installe aussi bin/sd / bin/piper s’ils manquent. Une bannière « Models: … » apparaît quand de nouvelles offres tiennent dans votre palier VRAM. Après un téléchargement, redémarrez pour que etc/modeld.yaml voie les chemins.

memory

memory

Remember a fact (“I prefer French”), then Recall. Back in Chat, the next message should be able to use that context (mem.context injection before infer). Auto-remember from chat is on by default (Settings): durable facts get a [chat] badge; secrets are filtered.

Remember un fait (« je préfère le français »), puis Recall. De retour dans Chat, le message suivant doit pouvoir s’en servir (injection mem.context avant l’inférence). La mémorisation auto depuis le chat est activée par défaut (Settings) : les faits durables ont un badge [chat] ; les secrets sont filtrés.

notes

notes

Notes tab: title + body → Create, then List. After a Preview update, the packaged module is copied on boot if it is newer. To create a note via agent: Agents tab or Chat /agent → a task like “create a note titled cohort with content hello”.

Onglet Notes : titre + corps → Create, puis List. Après une update Preview, le module empaqueté est recopié au boot s’il est plus récent. Via agent : onglet Agents ou Chat /agent → une tâche du type « create a note titled cohort with content hello ».

tasks

tasks

Tasks tab: create / list / complete. The same JSON store is visible to agents via tasks.list / tasks.create.

Onglet Tasks : créer / lister / terminer. Le même store JSON est visible aux agents via tasks.list / tasks.create.

modules

modules

Installed packages with declarative_ui appear under Modules (not notes, tasks, or ext-rt). Open a tab: heading, form or button, table bound to a tool. Submit goes through the same cap review as module.invoke. Invalid ui/index.html shows an error banner (no partial widgets). Chat « create a module » or Scenarios can scaffold / package / install one.

Les paquets installés avec declarative_ui apparaissent sous Modules (pas notes, tasks ni ext-rt). Ouvrir un onglet : heading, formulaire ou bouton, table liée à un outil. Soumettre passe par la même revue de caps que module.invoke. Un ui/index.html invalide affiche une bannière (pas de widgets partiels). Le chat « crée un module » ou Scénarios peut scaffolder / packager / installer.

agents

agents

Create an agent with a task and a model. Preview skills: notes-writer, research, file-author, planner, tasks. Optional MCP: copy share/mcp/servers.yaml.example and add stdio servers. Sensitive actions raise a confirmation banner. Deny once, Accept another. Timeout is deny. Open Detail for the step timeline, Pause / Resume / Steer.

Créez un agent avec une tâche et un modèle. Skills Preview : notes-writer, research, file-author, planner, tasks. MCP optionnel : copiez share/mcp/servers.yaml.example et ajoutez des serveurs stdio. Une action sensible affiche une bannière. Deny une fois, Accept une autre. Timeout = refus. Ouvrez Détail pour la timeline, Pause / Reprendre / Steer.

settings

settings

Language en ↔ fr, default agent model / max steps, search engine, auto-remember, Secrets vault, local module catalogue, schedules. Preferences persist in var/run/preferences.json.

Langue en ↔ fr, modèle agent / max steps, moteur de recherche, mémorisation auto, vault Secrets, catalogue local de modules, schedules. Les préférences persistent dans var/run/preferences.json.

audit

audit

Audit tab → Refresh (signed events). Kill aos-auditd: chat must continue; the supervisor restarts auditd in the background.

Onglet Audit → Refresh (événements signés). Tuer aos-auditd : le chat doit continuer ; le superviseur relance auditd en arrière-plan.
