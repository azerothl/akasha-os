Preview starts offline. After models are set up, chat is expected to work without leaving the machine. Network egress is a choice you make — not something the host turns on in the background. La Preview démarre hors ligne. Une fois les modèles réglés, le chat est censé fonctionner sans quitter la machine. La sortie réseau est un choix que vous faites — pas quelque chose que l’hôte active en arrière-plan.

Offline by default

Hors ligne par défaut

The default mode is offline_strict: egress is denied until you enable Allow network in the sidebar or Settings. Search, page browse, file download, and GitHub feedback submit are explicit actions. There is no automatic upload of chats or memories.

Le mode par défaut est offline_strict : la sortie est refusée tant que vous n’activez pas Allow network dans la barre latérale ou Settings. Recherche, parcours de page, téléchargement et envoi de feedback GitHub sont des actions explicites. Il n’y a pas d’upload automatique des chats ou des mémoires.

How this relates to chat

Lien avec le chat

Local inference, notes, tasks, memory, and agent loops on the host do not need the network grant. When Allow network is off, a web search should fail with offline_strict — that is the intended proof that deny-by-default is real. Turn the grant on only when you want search, browse, fetch, or a one-click GitHub issue from Feedback.

L’inférence locale, notes, tasks, mémoire et boucles agent sur l’hôte n’ont pas besoin du grant réseau. Quand Allow network est éteint, une recherche web doit échouer avec offline_strict — c’est la preuve voulue que le refus par défaut est réel. N’activez le grant que pour chercher, parcourir, télécharger, ou ouvrir une issue GitHub en un clic depuis Feedback.

Allow network, then search

Autoriser le réseau, puis chercher

Enable Allow network, then ask for a search (for example “Akasha OS seL4”). You should see title and URL results. The search engine lives in Settings under Web: auto tries Brave, then DuckDuckGo, then Bing. You can also force brave, duckduckgo, or bing.

Activez Allow network, puis demandez une recherche (par exemple « Akasha OS seL4 »). Vous devriez voir titres et URL. Le moteur est dans Settings sous Web : auto essaie Brave, puis DuckDuckGo, puis Bing. Vous pouvez aussi forcer brave, duckduckgo ou bing.

Secrets

Secrets

Optional Brave and GitHub keys live in Settings → Secrets (encrypted vault; master key in the OS keyring). A legacy var/secrets/keys.yaml is migrated on boot. Without a Brave key, auto falls through to DuckDuckGo then Bing HTML. github_token is only for one-click Feedback issues — not for chat egress.

Les clés Brave et GitHub optionnelles sont dans Settings → Secrets (vault chiffré ; clé maître dans le keyring OS). Un ancien var/secrets/keys.yaml est migré au boot. Sans clé Brave, auto bascule sur DuckDuckGo puis Bing HTML. github_token sert uniquement aux issues Feedback en un clic — pas à la sortie chat.

Browse and download

Parcourir et télécharger

With network on, paste a URL and use Browse (web.browse). Preview returns a title and extracted text, without running JavaScript. Download URL (net.fetch) saves the raw file under /downloads (on disk: var/storage/data/downloads/). You can also generate a file (for example pdf or png at /downloads/test.pdf) and open the downloads folder from the UI.

Réseau activé : collez une URL et utilisez Browse (web.browse). La Preview renvoie un titre et du texte extrait, sans exécuter de JavaScript. Download URL (net.fetch) enregistre le fichier brut sous /downloads (sur disque : var/storage/data/downloads/). Vous pouvez aussi générer un fichier (par exemple pdf ou png en /downloads/test.pdf) et ouvrir le dossier downloads depuis l’UI.

Still a choice

Toujours un choix

Leaving Allow network off is a valid everyday mode. Turn it on for the paths you mean to exercise, then turn it off again if you want the host quiet.

Laisser Allow network éteint est un mode quotidien valide. Activez-le pour les chemins que vous voulez exercer, puis éteignez-le si vous voulez un hôte silencieux.
