Network is off by default (offline_strict). Chat after model setup must work without it. Search, fetch, and GitHub feedback submit are explicit actions — not automatic uploads. Le réseau est éteint par défaut (offline_strict). Le chat après le réglage des modèles doit marcher sans lui. Recherche, fetch et envoi de feedback GitHub sont des actions explicites — pas des uploads automatiques.

prove deny

prouver le refus

  1. Leave Allow network (sidebar) off.
  2. Laissez Allow network (barre latérale) éteint.
  3. Search must fail with offline_strict.
  4. La recherche doit échouer avec offline_strict.

allow, then search

autoriser, puis chercher

  1. Enable Allow network.
  2. Activez Allow network.
  3. Search (for example “Akasha OS seL4”) → title/URL results.
  4. Cherchez (par exemple « Akasha OS seL4 ») → titres / URL.

Optional Brave key in var/secrets/keys.yaml:

Clé Brave optionnelle dans var/secrets/keys.yaml : 

keys:
  brave_search_api_key: "BSA..."
  github_token: "ghp_..."   # one-click Feedback issues

Without a Brave key, search uses DuckDuckGo HTML. github_token is only for one-click Feedback issues.

Sans clé Brave, la recherche utilise DuckDuckGo HTML. github_token sert uniquement aux issues Feedback en un clic.

download and generate a file

télécharger et générer un fichier

  1. With network ON, paste an image URL → Download URL.
  2. Réseau ON : coller une URL d’image → Download URL.
  3. File lands under Fichier sous /downloads (var/storage/data/downloads/).
  4. Generate file: format pdf or png, path /downloads/test.pdf, then Open downloads.
  5. Generate file : format pdf ou png, chemin /downloads/test.pdf, puis Open downloads.
