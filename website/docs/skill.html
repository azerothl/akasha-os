A skill is a Markdown recipe. In ten minutes you can copy one into Preview 0.16.1 without cargo, without a kernel pull request, and without granting the commercial license. Un skill est une recette Markdown. En dix minutes vous pouvez en copier une dans la Preview 0.16.1 sans cargo, sans pull request noyau, et sans accorder la licence commerciale.

What this is not

Ce que ce n’est pas

Not a WASM module, not a crate, not the five skills that ship in the zip. Those live under share/skills/. Yours go under var/skills/ so an update overlay does not wipe them. Host OS code stays AGPL. This path is MIT — see ADR 0006.

Pas un module WASM, pas un crate, pas les cinq skills du zip. Celles-là vivent sous share/skills/. Les vôtres vont sous var/skills/ pour qu’un overlay de mise à jour ne les efface pas. Le code hôte reste AGPL. Ce chemin est MIT — voir l’ADR 0006.

Ten minutes

Dix minutes

  1. Preview must already be installed. If it is not, install first, then the 15-minute path.
  2. La Preview doit déjà être installée. Sinon, installer d’abord, puis le chemin de 15 minutes.
  3. Create a folder named with the skill id (lowercase, digits, hyphens; 2–33 characters; start with a letter). Example: morning-brief or ping.
  4. Créez un dossier nommé avec l’id du skill (minuscules, chiffres, tirets ; 2–33 caractères ; commence par une lettre). Exemple : morning-brief ou ping.
  5. Put SKILL.md in that folder under the Preview home var/skills/ — not share/skills/.
  6. Placez SKILL.md dans ce dossier sous le home Preview var/skills/ — pas share/skills/.
  7. Restart Preview. Agents tab or Chat: start an agent with that skill, or ask in a way that matches when_to_use.
  8. Redémarrez la Preview. Onglet Agents ou Chat : lancez un agent avec ce skill, ou demandez quelque chose qui correspond à when_to_use.

Where the file goes

Où va le fichier

Windows: %LOCALAPPDATA%\AgentOS-Preview\var\skills\<name>\SKILL.md

Windows : %LOCALAPPDATA%\AgentOS-Preview\var\skills\<name>\SKILL.md

Linux and macOS (Apple Silicon): ~/.local/share/agentos-preview/var/skills/<name>/SKILL.md

Linux et macOS (Apple Silicon) : ~/.local/share/agentos-preview/var/skills/<name>/SKILL.md

From a git clone with AOS_HOME at the repo, copy into var/skills/<name>/ instead. Preview loads SKILL.md only — a SKILL.fr.md is for humans.

Depuis un clone git avec AOS_HOME sur le dépôt, copiez vers var/skills/<name>/. La Preview ne charge que SKILL.md — un SKILL.fr.md est pour les humains.

Path A — copy the example

Chemin A — copier l’exemple

Fastest. In Preview: Settings → Local module catalogue → enable Community catalogue → Fetch community index → Install morning-brief (cap review unchanged). Or download morning-brief/SKILL.md into var/skills/morning-brief/. Restart. Ask “Give me a morning brief”. It reads memory, open tasks, and notes. It does not use the network. Folder notes: community/skills/morning-brief.

Le plus rapide. Dans la Preview : Settings → Catalogue local de modules → activer le catalogue communautaire → Récupérer l’index → Installer morning-brief (revue de caps inchangée). Ou téléchargez morning-brief/SKILL.md dans var/skills/morning-brief/. Redémarrez. Demandez « Give me a morning brief » (la recette agent est en anglais). Il lit la mémoire, les tâches ouvertes et les notes. Pas de réseau. Dossier : community/skills/morning-brief.

Path B — write ping

Chemin B — écrire ping

Save this as var/skills/ping/SKILL.md. The agent body is English, like the shipped skills. Keep license: MIT. Restart, then ask “ping”.

Enregistrez ceci comme var/skills/ping/SKILL.md. Le corps agent est en anglais, comme les skills livrés. Gardez license: MIT. Redémarrez, puis demandez « ping ». 

---
name: ping
description: Reply with pong and stop
license: MIT
when_to_use: User says ping or asks if a custom skill is loaded.
tools:
  - goal.complete
---
# Ping

Reply with the single word pong. Then call goal.complete.
Do not search the web. Do not create notes or tasks.

Share it

Le partager

A Show and tell Discussion with the SKILL.md pasted in is enough. That is not a CLA. A pull request is welcome only under community/ — never under crates/. Mixed PRs (host + skill) are refused. Hangout: community.

Une Discussion Show and tell avec le SKILL.md collé suffit. Ce n’est pas un CLA. Une pull request n’est bienvenue que sous community/ — jamais sous crates/. Les PR mixtes (hôte + skill) sont refusées. Lieu de rencontre : community.
