Lifecycle

Cycle de vie

module.scaffold → module.package → module.install with cap review (fail-closed). Script kind bundles prebuilt ext-rt WASM. Rust kind adds module.compile (critical cap, offline cargo). Installed packages live under var/modules/.

module.scaffold → module.package → module.install avec revue de caps (fail-closed). Le kind script embarque le WASM ext-rt précompilé. Le kind Rust ajoute module.compile (cap critique, cargo hors ligne). Paquets installés sous var/modules/.
