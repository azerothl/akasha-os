Create est une app module riche dans la Preview 0.17.0 : espace volet scindé, presets, calques et UI de génération — rendu par l’hôte DeclUI générique (ui.contract: 2), pas un onglet egui codé à la main.

Platform vs package

Plateforme vs paquet

Image and video generation stay host services (media.image.generate). The Create package owns UI state under /documents/create/**. Agents can still call media.image.generate when Create is uninstalled.

La génération image et vidéo reste des services hôte (media.image.generate). Le paquet Create possède l’état UI sous /documents/create/**. Les agents peuvent toujours appeler media.image.generate si Create est désinstallé.

Salon artefacts

Artefacts salon

In-app Room mode (salon) is chat-scoped — distinct from device capture. Session transcripts and room turns live under the chat session store; device PNGs from camera capture live under var/sessions/<id>/devices/. UI rules: docs/UI.md.

Le mode Room (salon) est lié au chat — distinct de la capture périphériques. Transcripts et tours salon sont dans le store de session chat ; les PNG caméra sont sous var/sessions/<id>/devices/. Règles UI : docs/fr/UI.md.
