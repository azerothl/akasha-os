A module is dual-surface: tools for agents, a closed widget tree for you. Preview 0.16.0 can scaffold, package, and install one without cargo. That is longer than a skill, and it is still not a kernel pull request. Un module est dual-surface : des outils pour les agents, un arbre de widgets fermé pour vous. La Preview 0.16.0 peut en scaffolder, packager et installer un sans cargo. C’est plus long qu’un skill, et ce n’est toujours pas une pull request noyau.

What this is not

Ce que ce n’est pas

Not notes, tasks, canvas, or ext-rt — those are bundled. Not HTML/JS or a webview (closed declarative_ui only). Not a public marketplace: install is a local signed catalogue plus cap review. Guest packages default MIT in community/; the WASM SDK is Apache-2.0. The host stays AGPL — ADR 0006.

Pas notes, tasks, canvas ni ext-rt — ceux-là sont bundlés. Pas d’HTML/JS ni de webview (declarative_ui fermé seulement). Pas de marketplace public : l’install est un catalogue local signé plus la revue de caps. Les paquets guest sont MIT par défaut dans community/ ; le SDK WASM est Apache-2.0. L’hôte reste AGPL — ADR 0006.

Chemin A — demander à l’agent (sans cargo)

This is the tester path. Pick a name that is not bundled (cohortmod, pingmod): lowercase, digits, hyphens; 2–32 characters; start with a letter.

C’est le chemin testeur. Choisissez un nom qui n’est pas bundlé (cohortmod, pingmod) : minuscules, chiffres, tirets ; 2–32 caractères ; commence par une lettre.

Where the files go

Où vont les fichiers

Authoring lives under the Preview home var/modules/: source in src/<name>/ (script handlers.yaml), package at packages/<name>.aospkg. Windows home is %LOCALAPPDATA%\AgentOS-Preview; Linux and macOS use ~/.local/share/agentos-preview.

L’authoring vit sous le home Preview var/modules/ : source dans src/<name>/ (handlers.yaml script), paquet dans packages/<name>.aospkg. Home Windows : %LOCALAPPDATA%\AgentOS-Preview ; Linux et macOS : ~/.local/share/agentos-preview.

The host copies a closed widget tree into ui/index.html (default: heading + form + table). Invalid documents show an error banner — no partial widgets, no HTML/JS. Everyday map: use → Extend.

L’hôte copie un arbre de widgets fermé dans ui/index.html (défaut : heading + form + table). Un document invalide affiche une bannière d’erreur — pas de widgets partiels, pas d’HTML/JS. Carte quotidienne : use → Étendre.

Path B — Settings

Chemin B — Settings

Same three intents without Chat: Settings → Modules, module.scaffold (kind script), then module.package, then module.install. Cap review is the same. Uninstall from Settings → Installed modules (not the bundled four). Re-install still works.

Les trois mêmes intents sans Chat : Settings → Modules, module.scaffold (kind script), puis module.package, puis module.install. Même revue de caps. Désinstall depuis Settings → Installed modules (pas les quatre bundlés). Réinstaller marche encore.

Rust compile (not the first module)

Compile Rust (pas le premier module)

module.scaffold kind rust plus module.compile is a critical cap: confirmation even in High trust, static refuse of unsafe / ambient std::fs / net / process, CARGO_NET_OFFLINE=true. Guest code uses modules/sdk (Apache-2.0). Skip this until a script module has run on your machine.

module.scaffold kind rust plus module.compile est une cap critique : confirmation même en High, refus statique de unsafe / std::fs ambiant / net / process, CARGO_NET_OFFLINE=true. Le guest utilise modules/sdk (Apache-2.0). Passez tant qu’un module script n’a pas tourné chez vous.

Share it

Le partager

Copy var/modules/packages/<name>.aospkg into a Show and tell Discussion — that is not a CLA. A pull request belongs under community/modules/ only, never crates/. Whoever installs still gets cap review. There is no public store. Hangout: community.

Copiez var/modules/packages/<name>.aospkg dans une Discussion Show and tell — ce n’est pas un CLA. Une pull request va sous community/modules/ seulement, jamais crates/. Qui installe a encore la revue de caps. Pas de store public. Lieu de rencontre : community.
