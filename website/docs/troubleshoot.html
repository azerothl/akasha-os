Troubleshoot

Open the in-app Troubleshoot surface (sidebar / overflow). It collects host diagnostics: NVIDIA / GPU presence, AOS_HOME paths, and recent logs. When findings exist, you can open a GitHub report with the collected body. Copy works on the Troubleshoot body the same way as on chat messages.

Ouvrez la surface in-app Troubleshoot (rail / overflow). Elle collecte des diagnostics hôte : présence NVIDIA / GPU, chemins AOS_HOME, logs récents. Quand il y a des findings, vous pouvez ouvrir un rapport GitHub avec le corps collecté. Copy fonctionne sur le corps Troubleshoot comme sur les messages de chat.

  • Prefer Troubleshoot before reinstalling — it keeps var/ context.
  • Préférez Troubleshoot avant de réinstaller — ça garde le contexte var/.
  • Security issues still go through Feedback with Create a GitHub issue unchecked so the report stays local.
  • Les sujets sécurité passent encore par Feedback avec Create a GitHub issue décoché pour rester local.

Updates

Mises à jour

When a newer GitHub Release exists, Preview can show a banner. Opt-in auto-download (Settings) stores the archive under var/updates/ in the background; the banner then says the update is ready — relaunch to apply. Apply overlays bin/ and share/ on the next launch without touching var/ or blindly overwriting your etc/*.yaml (conflicts get a .new sibling).

Quand une Release GitHub plus récente existe, la Preview peut afficher une bannière. Le téléchargement auto opt-in (Settings) stocke l’archive sous var/updates/ en arrière-plan ; la bannière dit alors que la mise à jour est prête — relancer pour appliquer. L’apply superpose bin/ et share/ au prochain lancement sans toucher var/ ni écraser aveuglément vos etc/*.yaml (les conflits reçoivent un frère .new).

  1. See the update banner (or enable auto-download in Settings).
  2. Voir la bannière de mise à jour (ou activer le téléchargement auto dans Settings).
  3. Quit Preview cleanly when the archive is ready.
  4. Quitter proprement la Preview quand l’archive est prête.
  5. Relaunch — overlay applies; check What’s new for the tag you landed on.
  6. Relancer — la superposition s’applique ; vérifiez Nouveauté pour le tag obtenu.

Fully silent download-and-apply in one shot is not finished — you stay in control of when the overlay lands. See Limits · Updates.

Le télécharger-et-appliquer silencieux en un seul geste n’est pas terminé — vous gardez la main sur le moment de la superposition. Voir Limits · Mises à jour.

When still stuck

Toujours bloqué

Re-run the Release installer from Install if the overlay cannot apply. Ask on community (GitHub Discussions) with OS / GPU and what Troubleshoot reported. File the cohort path from Feedback so var/feedback/ is attached.

Relancez l’installeur Release depuis Install si la superposition ne peut pas s’appliquer. Demandez sur community (GitHub Discussions) avec OS / GPU et ce que Troubleshoot a rapporté. Envoyez le chemin cohorte depuis Feedback pour attacher var/feedback/.
