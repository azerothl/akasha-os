package (recommended)

paquet (recommandé)

Builds release bins, packages WASM modules, assembles dist/AgentOS-Preview-<ver>-…. GGUFs are skipped (-SkipModels / SKIP_MODELS=1) and download on first run.

Compile les binaires release, empaquete les modules WASM, assemble dist/AgentOS-Preview-<ver>-…. Les GGUF sont omis (-SkipModels / SKIP_MODELS=1) et se téléchargent au premier lancement. 

# Windows
.\packaging\build-preview.ps1 -SkipModels -RequireCuda

# Linux
SKIP_MODELS=1 REQUIRE_CUDA=1 ./packaging/build-preview.sh

Then set AOS_HOME to the dist folder and run bin/aos-session, or use the tree like a Release install. Optional Linux container build: packaging/docker-build-linux.sh.

Ensuite pointez AOS_HOME sur le dossier dist et lancez bin/aos-session, ou traitez l’arbre comme une install Release. Build Linux optionnel en conteneur : packaging/docker-build-linux.sh.

dev run

run de développement

From the repo root after a successful release build of the Preview crates (or after build-preview.*). Still requires NVIDIA.

Depuis la racine du dépôt après un build release des crates Preview (ou après build-preview.*). NVIDIA toujours requis. 

# Windows
$env:AOS_HOME = (Resolve-Path .)
cargo run -p aos-session --release

# Linux
export AOS_HOME="$(pwd)"
cargo run -p aos-session --release
