Most agent stacks are applications sitting on a general-purpose OS. Akasha OS treats autonomy as a system problem instead. Preview 0.16.1 is still a host app you install and launch — not a bootable image. The seL4 track in the repository is a separate line of work. La plupart des stacks agents sont des applications posées sur un OS généraliste. Akasha OS traite l’autonomie comme un problème système. La Preview 0.16.1 reste une appli hôte que vous installez et lancez — pas une image bootable. La piste seL4 du dépôt est une ligne de travail séparée.

What this page is for

À quoi sert cette page

Before you install, it helps to know how Preview differs from a chat wrapper or an “AI desktop.” The sections below map each idea to something you can already try in the UI.

Avant d’installer, il est utile de voir en quoi la Preview diffère d’un wrapper de chat ou d’un « bureau IA ». Les sections ci-dessous relient chaque idée à quelque chose que vous pouvez déjà essayer dans l’interface.

Not another chat wrapper

Pas un wrapper de chat de plus

A neighboring chat product can embed models and tools, but it still borrows the ambient trust of your user account on Windows, Linux, or macOS. Akasha OS Preview puts agents, models, and tools behind capability tokens and a signed audit trail. When an agent wants to write a note or call a tool, that action is an intent on the system bus — not an unchecked call into the host OS.

Un produit de chat voisin peut embarquer des modèles et des outils, mais il emprunte encore la confiance ambiante de votre compte utilisateur sur Windows, Linux ou macOS. Akasha OS Preview place agents, modèles et outils derrière des jetons de capacité et un journal d’audit signé. Quand un agent veut écrire une note ou appeler un outil, cette action est un intent sur le bus système — pas un appel non contrôlé vers l’OS hôte.

Capabilities instead of ambient trust

Des capacités plutôt qu’une confiance ambiante

An agent may act only inside the tokens it was granted: a file path, a network route, a tool name, a lifetime. Those tokens are meant to be unforgeable and revocable. There is no coarse “this agent may do everything the user can” shortcut. Broad grants remain possible when you choose them, but they stay visible in the Caps tab and can be taken back; sensitive steps still raise a confirmation banner that times out to deny.

Un agent n’agit que dans les jetons qu’on lui a donnés : un chemin de fichier, une route réseau, un nom d’outil, une durée. Ces jetons sont conçus pour être infalsifiables et révocables. Il n’y a pas de raccourci grossier du type « cet agent peut tout ce que l’utilisateur peut ». Des grants larges restent possibles si vous les choisissez, mais ils restent visibles dans l’onglet Caps et peuvent être retirés ; les étapes sensibles affichent encore une bannière de confirmation qui expire en refus.

Semantic IPC

IPC sémantique

On this host, an agent’s first language is typed intents on the bus — for example creating a note or generating an image — rather than speaking POSIX open / read / write as its native dialect. POSIX still exists underneath Windows and Linux. Modules expose a typed schema that the human UI and the agent consume the same way, so Notes and Tasks stay dual-surface: one store, two faces.

Sur cet hôte, la première langue d’un agent, ce sont des intents typés sur le bus — créer une note ou générer une image, par exemple — plutôt que de parler POSIX open / read / write en dialecte natif. POSIX existe toujours sous Windows et Linux. Les modules exposent un schéma typé consommé de la même façon par l’UI humaine et par l’agent : Notes et Tasks restent dual-surface, un seul store, deux faces.

First-class GPU and models

GPU et modèles de premier plan

Inference latency is the bottleneck, not a classic CPU scheduler. Preview probes VRAM, RAM, and disk on first launch, suggests a model pack for your tier, and runs GGUF inference through modeld as a system service. You can pin auto / GPU / CPU in Settings and, on NVIDIA, migrate mid-token without cancelling the turn. Image and speech packs download from Models when you want them; they are not forced into the first-run zip.

Le goulot, c’est la latence d’inférence, pas un scheduler CPU classique. La Preview sonde VRAM, RAM et disque au premier lancement, propose un pack de modèles pour votre palier, et fait tourner l’inférence GGUF via modeld comme service. Vous pouvez fixer auto / GPU / CPU dans Settings et, sur NVIDIA, migrer en milieu de génération sans annuler le tour. Les packs image et voix se téléchargent depuis Models quand vous le souhaitez ; ils ne sont pas imposés dans le zip de first-run.

Offline by default

Hors ligne par défaut

Network egress starts denied (offline_strict). After models are on disk, Chat is expected to work with Allow network left off. Search, browse, fetch, and opening a GitHub feedback issue are explicit actions you turn on when you mean them. There is no automatic upload of your session.

La sortie réseau commence refusée (offline_strict). Une fois les modèles sur disque, le Chat doit fonctionner avec Allow network éteint. Recherche, browse, fetch et l’ouverture d’une issue GitHub de feedback sont des actions explicites que vous activez quand vous le voulez. Il n’y a pas d’upload automatique de votre session.

Host now, seL4 later

Hôte maintenant, seL4 plus tard

Preview is userspace scaffolding on Windows, Linux, or macOS. That choice lets cohort testers install without cargo and send feedback from the UI. The seL4 / Microkit track in the repo explores a bootable future; it is not what GitHub Releases ship today. Keeping that distinction visible is part of the product story.

La Preview est un échafaudage en userspace sur Windows, Linux ou macOS. Ce choix permet aux testeurs de cohorte d’installer sans cargo et d’envoyer un retour depuis l’UI. La piste seL4 / Microkit du dépôt explore un futur bootable ; ce n’est pas ce que les Releases GitHub livrent aujourd’hui. Garder cette distinction visible fait partie de l’histoire produit.
