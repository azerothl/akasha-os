Akasha OS is the medium agents run in; Preview is a local host app you install on Windows or Linux — not a bootable OS, not cloud SaaS.

Akasha OS est le milieu où les agents existent ; la Preview est une appli hôte locale à installer sur Windows ou Linux — pas un OS bootable, pas un SaaS cloud.

Host Preview

Preview hôte

You download a zip or tarball and run an installer script. The UI and daemons live under your user profile — the same kind of host app you already know how to launch.

Vous téléchargez une archive et lancez un script d’installation. L’UI et les daemons vivent sous votre profil utilisateur — le même genre d’appli hôte que vous savez déjà démarrer.

NVIDIA

A recent NVIDIA GPU is recommended for comfortable local inference. Without one, Preview still starts on a slower CPU path in the same package.

Un GPU NVIDIA récent est recommandé pour une inférence locale confortable. Sans GPU, la Preview démarre quand même sur un chemin CPU plus lent, dans le même paquet.

Not a bootable OS

Pas un OS bootable

This release is not a disk image you boot into. A separate seL4 track exists in the repository for that longer-term goal.

Cette version n’est pas une image disque que vous démarrez. Une piste seL4 distincte existe dans le dépôt pour cet objectif à plus long terme.
