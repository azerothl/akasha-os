Akasha OS

Akasha OS is the medium agents run in. Preview 0.10.0 installs as a host application on Windows or Linux: chat sessions, memory, WASM modules, agents, and local models are system services with explicit capabilities and a signed audit trail — not plugins glued onto a chat window.

Akasha OS est le milieu où les agents existent. La Preview 0.10.0 s’installe comme une application hôte sur Windows ou Linux : sessions de chat, mémoire, modules WASM, agents et modèles locaux sont des services système avec des capacités explicites et un journal d’audit signé — pas des plugins collés à une fenêtre de chat.

  • Memory that persists across sessions
  • Mémoire qui survit aux sessions
  • Revocable capability tokens
  • Jetons de capacité révocables
  • Local GPU inference as a service
  • Inférence GPU locale comme service
  • Agents with skills, tools, and audit
  • Agents avec skills, outils et audit

Host Preview

Preview hôte

You download a zip or tarball and run an installer script. The UI and daemons live under your user profile — the same kind of host app you already know how to launch.

Vous téléchargez une archive et lancez un script d’installation. L’UI et les daemons vivent sous votre profil utilisateur — le même genre d’appli hôte que vous savez déjà démarrer.

NVIDIA

A recent NVIDIA GPU is recommended for comfortable local inference. Without one, Preview still starts on a slower CPU path in the same package.

Un GPU NVIDIA récent est recommandé pour une inférence locale confortable. Sans GPU, la Preview démarre quand même sur un chemin CPU plus lent, dans le même paquet.

Not a bootable OS

Pas un OS bootable

This release is not a disk image you boot into. A separate seL4 track exists in the repository for that longer-term goal.

Cette version n’est pas une image disque que vous démarrez. Une piste seL4 distincte existe dans le dépôt pour cet objectif à plus long terme.
