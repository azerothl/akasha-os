Why Agent OS

Pourquoi Agent OS

Most agent stacks are apps on top of a general-purpose OS. Agent OS treats agents, models, tools, and memory as first-class system services with explicit capabilities, audit, and policy — so autonomy stays bounded and observable.

La plupart des stacks agents sont des applications sur un OS généraliste. Agent OS traite agents, modèles, outils et mémoire comme des services système, avec capacités explicites, audit et politiques — pour que l’autonomie reste bornée et observable.

Capabilities, not ambient trust

Des capacités, pas une confiance ambiante

Agents act only with unforgeable, revocable tokens. No coarse global permissions.

Les agents n’agissent qu’avec des jetons infalsifiables et révocables. Pas de permissions globales trop grossières.

Semantic IPC

IPC sémantique

Typed intents on the system bus, not POSIX as the agent’s native language.

Des intents typés sur le bus système, pas POSIX comme langage natif de l’agent.

GPU as a first-class device

Le GPU comme périphérique de premier plan

Placement, scheduling, and local GGUF inference are part of the runtime, not an app afterthought.

Placement, ordonnancement et inférence GGUF locale font partie du runtime, pas d’un à-côté applicatif.

Offline by default

Offline par défaut

Network search and fetch are opt-in. Egress is deny-by-default.

Recherche et fetch réseau sont en opt-in. La sortie réseau est refusée par défaut.

Requirements

Prérequis

  • Windows 10/11 x64 orou Linux x64
  • NVIDIA GPU + recent driverpilote récent (nvidia-smi -L)
  • ~4 GB free disk (binaries + GGUF models on first run)
  • ~4 Go d’espace disque (binaires + modèles GGUF au premier lancement)

No macOS or CPU-only mode in Preview 0.1. Cohort status: P0–P4 and PV shipped; PC in progress.

Pas de macOS ni de mode CPU-only en Preview 0.1. Statut de la cohorte : P0–P4 et PV livrés ; PC en cours.

Quick start

Démarrage rapide

  1. Download the latest zip/tar.gz from GitHub Releases.
  2. Télécharger le dernier zip/tar.gz depuis GitHub Releases.
  3. install.ps1 (Windows) orou ./install.sh (Linux).
  4. Launch Agent OS Preview — first run downloads models if needed, then opens the in-app tutorial.
  5. Lancer Agent OS Preview — le premier lancement télécharge les modèles si besoin, puis ouvre le tutoriel intégré.
