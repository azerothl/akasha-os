# Illustration Studio curated assets

The three preview thumbnails in `thumbs/` come from [Poly Haven](https://polyhaven.com/).
They are CC0, like the source models. The model files and textures are fetched
from the [Poly Haven API](https://polyhaven.com/our-api) only when selected in
Illustration Studio. Each download is checked against the API's size and MD5
before the app records its source, author, dimensions, orientation, pivot and
license beside the local files.
