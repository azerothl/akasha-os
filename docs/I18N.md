# Internationalization (i18n)

**Language:** English | [Français](fr/I18N.md)

## Markdown docs

| Role | Location |
|------|----------|
| Primary (English) | `docs/` (English filenames) |
| Secondary (French) | `docs/fr/` — logical mirrors (`FEATURES.md`, `STATUS.md`, …) |
| Header | `Language: [English](…) \| [Français](…)` |

Canonical docs live under `docs/`. Root keeps `README.md`, `CONTRIBUTING.md`,
`CODE_OF_CONDUCT.md`, `SECURITY.md`, and license files only (`LICENSE`,
`LICENSE-COMMERCIAL.md`, `LICENSE-APACHE`, `LICENSE-MIT`, `NOTICE`).

**Public Preview manual** is separate: static HTML under `website/` with
inline EN/FR (`data-lang`). When HTML and Markdown overlap, follow
[SITE-MANUAL.md](SITE-MANUAL.md) (`packaging/site-docs-map.json` +
`./packaging/check-site-docs.ps1`).

French filename renames in `docs/fr/` (examples): `lan-cluster` →
`cluster-lan`, `functional-specs` → `specs-fonctionnelles`,
`technical-specs` → `specs-techniques`. Site digests must link the FR
mirror when it exists.

## UI

Preview egui uses **Settings → language** (`en` / `fr`), persisted in
`var/run/preferences.json` and synced to `onboarding.json`. Covers the
tutorial, tabs (including Settings), banner, Feedback, Troubleshooting,
Agents / Notes / Tasks action chrome, and agent detail (Detail / Steer).
Leftover: Scenarios tab (mostly hardcoded French) and the internal chat
role key `"vous"` — **P09.7**.

## Packaging

Release archives include `docs/` and `docs/fr/` so testers can read either
language offline (including `FEATURES.md`).
