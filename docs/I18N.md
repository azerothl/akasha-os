# Internationalization (i18n)

**Language:** English | [Français](fr/I18N.md)

## Markdown docs

| Role | Location |
|------|----------|
| Primary (English) | Repo root and `docs/` (English filenames where renamed) |
| Secondary (French) | `docs/fr/` — logical mirrors (`FEATURES.md`, `STATUS.md`, …) |
| Header | `Language: [English](…) \| [Français](…)` |

Root stubs keep old French paths (`specs-fonctionnelles.md`, etc.) pointing
here so historical links still work.

## UI

Preview egui uses **Settings → language** (`en` / `fr`), persisted in
`var/run/preferences.json` and synced to `onboarding.json`. Covers the
tutorial, tabs (including Settings), banner, Feedback, and Troubleshooting.
Agent detail chrome is still partly French-labelled (`Détail`, `Steer`).

## Packaging

Release archives include `docs/` and `docs/fr/` so testers can read either
language offline (including `FEATURES.md`).
