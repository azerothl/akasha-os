# Akasha OS

Akasha OS est un environnement local pour les agents, leurs outils et leurs applications. Les pages de référence expliquent les modules, les capacités du système et les interfaces de développement.

## Étendre le système

Consulter le SDK et le guide de création de module pour les points d’extension. Les permissions et capacités dépendent du contexte d’exécution. Utiliser la documentation du serveur MCP pour identifier les interfaces exposées.
