# Internationalisation (i18n)

**Langue :** [English](../I18N.md) | Français

## Documentation Markdown

| Rôle | Emplacement |
|------|-------------|
| Primaire (anglais) | Racine et `docs/` |
| Secondaire (français) | `docs/fr/` |
| En-tête | `Language: [English](…) \| [Français](…)` |

Les stubs à la racine (`specs-fonctionnelles.md`, etc.) redirigent vers les
chemins EN + FR.

## UI

L'UI egui utilise `onboarding.language` (`en` / `fr`) pour le tutoriel et
le chrome principal.
