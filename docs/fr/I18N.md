# Internationalisation (i18n)

**Langue :** [English](../I18N.md) | Français

## Documentation Markdown

| Rôle | Emplacement |
|------|-------------|
| Primaire (anglais) | `docs/` |
| Secondaire (français) | `docs/fr/` (`FEATURES.md`, `STATUS.md`, …) |
| En-tête | `Language: [English](…) \| [Français](…)` |

La documentation canonique est sous `docs/`. La racine ne garde que
`README.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md` et
les fichiers de licence (`LICENSE`, `LICENSE-COMMERCIAL.md`,
`LICENSE-APACHE`, `LICENSE-MIT`, `NOTICE`).

## UI

L'UI egui utilise **Settings → langue** (`en` / `fr`), persistée dans
`var/run/preferences.json` et synchronisée avec `onboarding.json`. Couvre
le tutoriel, les onglets (dont Settings), la bannière, Retour, Dépannage,
le chrome Agents / Notes / Tâches, et le détail agent (Détail / Orienter).
Reliquat : onglet Scénarios (surtout du français dur) et la clé interne de
rôle chat `"vous"` — **P09.7**.

## Packaging

Les archives Release incluent `docs/` et `docs/fr/` (dont `FEATURES.md`).
