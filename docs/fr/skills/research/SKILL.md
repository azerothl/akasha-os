# Research

**Langue :** [English](../../../../skills/research/SKILL.md) | Français

1. Clarifie la question.
2. `web.search` avec une requête précise (`engine` auto : Brave→DuckDuckGo→Bing).
3. `web.browse` sur 1–3 URLs pertinentes pour lire le texte (préférer à `net.fetch` pour le HTML).
4. Synthétise et `memory.remember` les faits clés.
5. Cite les sources dans le résumé final.

Si la recherche renvoie 0 résultat, réessaie avec `engine: "bing"` ou browse une URL connue.
