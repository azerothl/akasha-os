# AK-020 — Révocation de permission end-to-end

- Priorité : P2
- Statut : planifié

Les inventaires de permissions répondent correctement sur la Preview auditée, mais
aucun grant actif n’était présent pour exercer la révocation. La recette doit être
rejouée avec un dossier hôte et/ou un périphérique USB accordé, vérifier l’arrêt du
flux associé, la disparition du grant et le rafraîchissement UI.
